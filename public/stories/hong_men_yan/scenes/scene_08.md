@se se_heavy_thud.mp3
@shake 8 duration=500
一條大漢，側著盾牌撞翻衛士，直闖入帳。
披帷，西嚮立。
瞋目視你——頭髮上指，目眥盡裂。
帶劍，擁盾，一身酒市屠狗之氣，眼睛裡卻是燒著的火。
@se se_sword_draw.mp3
你下意識地按劍而跽，單膝支起，手按上了劍柄。八年征戰，你第一次在自己的帳中做出這個姿勢。
項羽: 「客何為者！？」
@show 張良 left calm
張良: 「沛公之參乘，樊噲者也。」
參乘——替主公擋刀的人。
他站在那裡，像一堵會喘氣的牆。帳中誰都看得明白——項莊的劍再舞一圈，這個人就會用血洗了這場宴席。

:: if 樊噲處置 == "賜酒"
你看著他，忽然笑了。
項羽: 「壯士！——賜之卮酒！」
好膽色。你這一生殺人無數，偏偏敬重不怕死的人。
左右卻給他端上了一「斗」卮酒——比賜的大了幾倍。刁難他。
樊噲拜謝，起，立而飲之。一滴不剩。
項羽: 「賜之彘肩！」
左右又給了他一條「生」彘肩，生的豬腿。
他看都不看，把盾牌反扣在地上，彘肩放在盾上，拔劍，切而啗之。生肉入口，面不改色。
項羽: 「壯士！能復飲乎？」
:: else
你按著劍，一言不發。
帳中的空氣凝住了。項莊的手還搭在劍上，張良的指尖掐進了掌心。
樊噲自己開了口，聲如洪鐘——「臣，沛公參乘樊噲！聞帳中劍氣逼人，特來為兩位主公助酒！」
張良趕忙躬身——「壯士遠來，大王何不賜酒？」
你盯了他半晌，終於抬了抬手。左右端上斗卮酒、生彘肩——存心刁難。他立而飲之，切生肉而啗之，眉頭都不皺一下。
你心裡那點慍怒，不知不覺變成了另一種東西。
:: endif
@wait 1000
樊噲: 「臣死且不避，卮酒安足辭！」
他把劍往盾上一拍，竟然反客為主，開了腔——
樊噲: 「夫秦王有虎狼之心。殺人如不能舉，刑人如恐不勝——天下皆叛之！」

:: if 降卒處置 == "坑殺"
「殺人如不能舉」。
這五個字砸下來的時候，你想起了新安城南。
那一夜之後安靜得可怕的二十萬人。
你有沒有做錯？你從來不許自己問這個問題。此刻它自己冒了出來。
:: endif
樊噲: 「懷王與諸將約曰：『先破秦入咸陽者，王之。』」
樊噲: 「今沛公先破秦入咸陽，毫毛不敢有所近，封閉宮室，還軍霸上，以待大王來。」
樊噲: 「勞苦而功高如此，未有封侯之賞；而聽細說，欲誅有功之人！」
他一字一頓，幾乎是吼出來的：

樊噲: 「此、亡、秦、之、續、耳！竊為大王不取也！」
@camera-reset
@wait 1500
亡秦之續。
你若殺了劉邦，就是第二個秦王。得天下者，從來不是殺人最多的那一個。
一個屠狗的粗人，把懷王之約、義與不義、天下人心，一條一條摔在你臉上。
而你——
項王未有以應。
項羽: 「……坐。」
樊噲從良坐。
@hide 樊噲 fade=600
@hide 張良 fade=600
@wait 1200
坐須臾，沛公起身。
劉邦: 「失陪——如廁。」
他順手招了樊噲出帳。你揮揮手，沒有在意。
如廁而已。
