你笑了。這是垓下之圍以來,你第一次笑。
項羽: 「天之亡我,我何渡為!」
項羽: 「且籍與江東子弟八千人渡江而西,今無一人還。縱江東父兄憐而王我,我何面目見之?」
項羽: 「縱彼不言——籍獨不愧於心乎?」
@hide 亭長 fade=800
你把跟了你五年的烏騅馬,贈給了亭長。
然後下馬,令騎兵皆下馬步行,持短兵接戰。
@wait 1500
最後一戰。
獨你一人,所殺漢軍數百。身被十餘創。
混戰中,你回頭,看見一張熟悉的臉——漢騎司馬呂馬童,你的故人。
項羽: 「若非吾故人乎?」
他不敢與你對視,側過臉去。
項羽: 「吾聞漢購我頭千金,邑萬戶——」
項羽: 「吾為若德。」
我把這份人情,送給你。
乃自刎而死。
@wait 2500

:: if 怒氣 >= 3
從函谷關那天的大怒,到烏江這最後一刀——你這一生的每個關口,都是那把火替你做的決定。
怒而攻關,怒而設宴,怒而摔璧。史書記下你兩次「大怒」,卻只記下你一次笑——就是把頭顱送給故人的這一次。
:: elif 范增信任 <= 0
你到死,都沒有再想起那個舉玉玦的老人。
鴻門帳中,他舉了三次。那是你這一生離天下最近的一刻,也是他離你最近的一刻。你一次都沒有回應。
:: else
「天之亡我,非戰之罪也。」
你至死都這麼相信。七十餘戰未嘗敗北,只輸了最後一場——這不是天,是什麼?
可是,鴻門的那場宴,不是天安排的。放走劉邦的,不是天。是你。
:: endif
@wait 2000
太史公司馬遷,後來把你寫進了「本紀」——那是帝王的傳記。你沒有稱帝,他卻說——政由羽出,近古以來,未嘗有也。
但他也寫下了另一段話:
「自矜功伐,奮其私智而不師古……欲以力征經營天下,五年卒亡其國,身死東城,尚不覺寤,而不自責,過矣。」
「乃引『天亡我,非用兵之罪也』——豈不謬哉!」
@wait 2000
一千年後,有個女詩人路過烏江,替你寫了四句:
生當作人傑,死亦為鬼雄。
至今思項羽,不肯過江東。
@wait 2500
