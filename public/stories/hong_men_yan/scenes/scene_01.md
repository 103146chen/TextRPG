@wait 1000
你是項籍，字羽，下相人。
你的祖父項燕，是楚國最後的大將——王翦破楚那年，他兵敗自殺。楚國亡了，項家四散，你跟著叔父項梁，流落到吳中。
@set 怒氣 = 0
@set 范增信任 = 0
項梁四處打點，讓你學習認字。學不成，丟下了；去學劍，又學不成。項梁動了怒。
項羽: 「書，足以記名姓而已。劍，一人敵，不足學——要學，就學萬人敵！」
叔父先是一愣，隨即大喜，親自教你兵法。你大略知其意，又不肯竟學。
你就是這樣的人。天下的道理，你只看最大的那一條。
@wait 1000
你長到八尺有餘，力能扛鼎，才氣過人，吳中子弟沒有不敬懼你的。
那一年，秦始皇帝出巡會稽，渡浙江。
天子儀仗，旌旗蔽日，車馬千乘。萬人空巷，伏在道旁，大氣都不敢出。
你和叔父，也在人群裡。
你看著那頂天子車蓋，從你面前緩緩駛過。
@camera zoom=1.8 x=-20 y=0 duration=3000 vignette=0.3 layer=bg
項羽: 「彼可取而代也。」
@show 項梁 center earnest
項梁一把摀住你的嘴，聲音壓得極低。
@sprite 項梁 shake intensity=5 duration=300
項梁: 「毋妄言——族矣！」
@camera-reset
@hide 項梁 fade=600
話雖如此，叔父看你的眼神，從那天起就不一樣了。

:: if 少年志向 == "復楚"
@set 舉玦回應 = true
國仇家恨，是你這一生最早學會的東西。
往後每一次揮兵，你都告訴自己——這是替楚國討回來的。
只是很多年後你才發現：
「恨一個已經亡了的秦」，和「治一個還活著的天下」，是兩回事。
:: elif 少年志向 == "取而代之"
你要的，是那個位子本身。
這句話若是劉邦說的，人們會笑他癡人說夢。但你說的，連叔父都信了。
你有那個力氣，有那個實力。
但缺的東西，要到很久以後才會顯出來。
:: else
力拔山兮氣蓋世。你天生就該站在萬人景仰的地方。
名，你這一生確實掙到了，兩千年後人們都還記得。
只是「名」這個東西，有時候會反過來，替你做決定。
:: endif
@wait 1000
數年後，陳勝揭竿而起，天下響應，豪傑蠭起。
你和叔父斬了會稽郡守，舉兵起事。吳中子弟八千人，渡江而西。
@set 江東八千子弟 = true
你二十四歲。從這一天起，你的名字讓天下發抖。
