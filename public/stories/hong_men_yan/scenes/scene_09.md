沛公出去，很久沒有回來。
你使都尉陳平去召。又是很久。
帳中的酒涼了。亞父的手指，在案上一下一下地敲。
@show 張良 center calm
終於，張良獨自入帳，長揖到地。
張良: 「沛公不勝桮杓，不能辭。」
張良: 「謹使臣良，奉白璧一雙，再拜獻大王足下；玉斗一雙，再拜奉大將軍足下。」
白璧一雙，獻你。玉斗一雙，獻亞父。禮數周全，滴水不漏。
項羽: 「沛公安在？」
張良: 「聞大王有意督過之，脫身獨去，已至軍矣。」
已至軍矣。
他跑了。
從你的宴席上，棄了車馬隨從，像個小吏一樣抄小路溜了。四十里，此刻人已在霸上大營。
你緩緩放下杯子。
帳中所有人都屏住了呼吸。

:: if 白璧 == "受"
你接過白璧，看了看，放在了座上。
項王則受璧，置之坐上。
史官後來記這場宴席的結尾，就用了這幾個字。
項羽(心聲): 「他嚇得從宴席上逃走——一個逃席的人，還能成什麼氣候。」
你甚至覺得，這一日賓主盡歡，劉邦已服，關中已定。
:: else
@set 怒氣 += 1
白璧砸在案上，緩緩滾向帳角。
滿帳武士的手都按上了刀。張良伏在地上，一動不動。
可你終究沒有下那道追擊的令。
項羽(心聲): 「追？追一個嚇破膽的逃席之人？我項籍，不屑。」
你不知道「不屑」和「放虎歸山」，在史書上會被寫成同一件事。
:: endif
@wait 1200
@hide 張良 fade=600
@show 范增 center angry
亞父接過那雙玉斗。
他看著玉斗，又看看你，忽然把它擲在地上——拔劍，一劍撞碎。
@se se_jade_break.mp3
@shake 5 duration=400
玉屑四濺。
@camera zoom=1.2 x=50 y=50 duration=800
范增: 「唉！豎子不足與謀！」
范增: 「奪項王天下者，必沛公也！」
@sprite 范增 shake intensity=5 duration=300
范增: 「吾屬今為之虜矣！」
@camera-reset
@hide 范增 fade=800
滿帳死寂。
「豎子」，罵項莊，罵他不明大義，袒護外人。
但帳中每一個人都知道，一語「豎子」，也向你而來。
七十歲的老人，一生奇計。今日三次舉玦、一場劍舞，全數落空。他預言了結局——我們這些人，將來都要做劉邦的俘虜。
你沒有動怒。
你只是覺得，老人家，言重了。
@wait 1500

:: if 說出曹無傷
數日後，霸上傳來一個消息:
沛公一回到軍中，立誅殺曹無傷。
你在席間隨口說出的那個名字，隔天就成了一具屍體。
劉邦回營第一件事，不是驚魂甫定，不是犒賞張良樊噲——是殺人滅患。乾淨，俐落，一天都不等。
而你，連走了四十里的劉邦都懶得追。
從此，再沒有漢營的人，敢向你遞一句話。
:: else
你始終沒有說出曹無傷的名字。
這個人後來還斷斷續續遞過幾次消息。你一次也沒有用——項籍用兵，堂堂正正，不靠小人。
到後來，連他自己都不再遞了。
一根埋在漢營的刺，就這樣鏽在了肉裡。
:: endif
@wait 1500
鴻門的宴席，散了。
你不知道，你剛剛放走的，是你這一生唯一一次，不用打仗，就能贏得天下的機會。
往後的每一次機會，都要用血去換。
