旁白: 四更天。你還未睡，帳外傳來馬蹄聲。
@se se_horse_gallop.mp3
@show 項伯 center earnest
旁白: 項伯掀帘而入，風塵滿面，靴上還沾著夜露。
項伯: 「籍兒，天亮的仗——打不得。」
旁白: 你皺起眉。叔父深夜不在營中，此刻回來，開口就是替劉邦說話。
項伯: 「沛公有話：『吾入關，秋毫不敢有所近，籍吏民，封府庫，而待將軍。所以遣將守關者，備他盜之出入與非常也。日夜望將軍至，豈敢反乎！』」
項伯: 「他派兵守關，是防盜賊，不是防你。他日夜盼著你來，哪裡敢反？」
旁白: 你冷笑一聲，還未開口，項伯又逼近一步。
項伯: 「籍兒，你想想——沛公不先破關中，你能這麼順利進來嗎？」
項伯: 「今人有大功而擊之，不義也。不如因善遇之。」
旁白: 「不義」二字，他咬得極重。
@sprite 項伯 shake intensity=4 duration=300
旁白: 帳中燭火劈啪一響。

?? choice
- text: 「叔父說得有理。他明日若親自來謝罪，此事便罷」
  set: { 項伯夜說: "許諾" }
- text: 「且慢——叔父，你深夜去往何處？」
  set: { 項伯夜說: "質問" }
- text: 「不必說了。傳令各營，天亮照打」
  goto: dawn_attack
??

:: if 項伯夜說 == "許諾"
旁白: 你沉吟半晌，點了頭。
項羽: 「好。他若親自來鴻門謝罪，此事便罷。」
旁白: 項伯鬆了一口氣，深深一揖。
旁白: 你沒有多想，叔父的話向來實在——有大功而擊之，不義。你項籍平生自負的，不就是一個「義」字？
:: else
@set 對項伯起疑 = true
旁白: 項伯的手頓了一下。
項伯: 「……韓公子張良，昔年於下邳救過我一命。他如今在沛公帳下。我去，是要他隨我離開，別陪著送死——誰知……」
旁白: 誰知，就帶回了劉邦的說辭，還喝了劉邦的酒，結了兒女親家。這些，他沒有全說，你也沒有全問。
旁白: 你看著叔父的眼睛。他沒有說謊——他這輩子不會說謊，這正是最讓你不安的地方——不會說謊的人，最容易被人利用。
項羽(心聲): 「一夜之間，劉邦的話，借我叔父的嘴，說進了我的中軍帳。」
旁白: 可他終究是你的叔父。項家的人。
項羽: 「……罷了。他若親自來鴻門謝罪，此事便罷。」
:: endif
@hide 項伯 fade=600
@wait 1200
旁白: 項伯連夜又出了營——你猜得到他去回話了。
旁白: 你沒有再召范增。
旁白: 你隱約知道，亞父若是聽見「此事便罷」四個字，會是什麼臉色。
@set 未告亞父 = true
旁白: 帳外，天邊已經有了一線灰白。
旁白: 今日，鴻門設宴。

項羽: 「大功？撿一座空城也叫大功？我在鉅鹿死了多少子弟——」
