起兵第三年，叔父項梁戰死於定陶。秦將章邯挾勝北上，把趙王圍在鉅鹿城裡。
趙國一日數次向楚求救。楚懷王拜宋義為上將軍，你為次將，范增為末將，北上救趙。
兵行至安陽，宋義下令紮營。一停，就是四十六天。
眼見入冬以來，天寒大雨，士卒凍飢，宋義卻無心戰事，大宴賓客，替兒子送行、飲酒尋歡。
而秦軍統帥王離，是王翦——正是那位在伐楚之戰中，迫使祖父自殺的將領——之孫。
——同一家人，不可永遠居於下風——
於是，你走入營帳，提出了想法：
項羽: 「疾引兵渡河，楚擊其外，趙應其內，破秦軍必矣。」
宋義慢條斯理地看著你，說了一句你一輩子忘不掉的話——
宋義: 「夫搏牛之虻，不可以破蟣蝨。」
宋義: 此舉乃待秦之疲。秦疲，則必舉——運籌帷幄是我的專長，將軍你還太嫩了！
宋義三兩言將你打發走，下令「強不可使者，皆斬」——很明顯，這條命令是為你量身打造的。
項羽（心聲）: 「國兵新破，王坐不安席。」
項羽（心聲）: 上將軍不引兵渡河，飽趙食、與趙并力攻秦，反而按兵不動，著實可恥！
項羽（心聲）: 「國家安危，在此一舉！」
那天早上，你走進上將軍的大帳。再出來時，手裡提著宋義的頭。
項羽: 「宋義與齊謀反楚，楚王陰令羽誅之！」
諸將懾服，無人敢動。楚懷王只得任命你為上將軍。
@wait 1200
渡過漳水，你下了那道此後兩千年兵家都要提起的命令——
皆沉船，破釜甑，燒廬舍，持三日糧。
沒有退路，沒有下一頓飯。回頭是死，向前也許能活。
九戰，絕其甬道，大破秦軍。
當你的士卒以一當十、呼聲動天的時候,，前來救趙的各路諸侯軍，全在壁壘上作壁上觀。
戰罷，你召見諸侯將領。他們進了轅門，無不膝行而前，莫敢仰視。
從這一天起，你是諸侯上將軍。天下義軍，皆歸你節制。
@wait 1200

大軍西進，行至新安。
降將章邯帶來的二十餘萬秦卒，一路上被諸侯軍當作奴隸驅使。夜裡，營中傳來秦卒的怨語——入關若勝，是替楚人打自己的家鄉；若敗，秦法族誅，家小不保。
軍吏來報——秦卒不服，恐入關為變。
二十餘萬人。比你的楚軍主力還多。
帳中燭火搖著。所有人都在等你一句話。

那一夜之後，新安城南安靜得可怕。
二十餘萬人，一夜之間，從大地上消失了。
你告訴自己——亂世，慈不掌兵。當年長平，武安君白起坑趙卒四十萬，秦人不也照樣拜他？
只是往後，關中的每一戶人家，都有一個沒能回來的兒子。
@set 秦地民心 = "恨"
:: elif 降卒處置 == "收編"
你留下了他們。范增皺著眉，沒有說話。
糧秣立刻減半。行軍慢了一倍。夜裡，楚人的營帳和秦人的營帳彼此提防，口音就是刀劍。
將領們的怨言一天比一天多——「這二十萬人，是兵，還是懸在我們背上的刀？」
最後你不得不把他們遠遠隔在後軍，派重兵「護送」——說是收編，其實是押著二十萬個隨時會炸開的人走路。
@set 秦地民心 = "疑"
:: else
你下令繳械，放他們回鄉。
范增急了——「放虎歸山！二十萬人回到關中，再握起鋤頭就是兵！」
你說——「無械之卒，不足為患。」
他們走的那天，有人在路邊對你的軍旗跪拜。也有人一言不發，頭也不回。
你不知道他們回鄉之後會說什麼——說項羽仁義？還是說，楚軍不過如此？
@set 秦地民心 = "觀望"
:: endif
@wait 1200
大軍繼續西進。函谷關，已經不遠了。
關的另一邊，是咸陽，是天下，是懷王與諸將的那句約定——
「先破秦入咸陽者，王之。」
