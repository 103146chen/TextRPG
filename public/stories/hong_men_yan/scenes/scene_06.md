旦日。
沛公真的來了——從百餘騎，只帶了一百多人，來見手握四十萬大軍的你。
@show 劉邦 center humble
他一進帳，腰就彎了下去。
劉邦: 「臣與將軍勠力而攻秦，將軍戰河北，臣戰河南。」
劉邦: 「然不自意能先入關破秦，得復見將軍於此。」
劉邦: 「今者有小人之言，令將軍與臣有郤……」
你居高臨下地看著他。
這個比你大二十四歲的男人，此刻像個做錯事的老僕。開口一個「臣」，閉口一個「將軍」。他把自己放進了你部下的位置。
「不自意」——他說他先入關，純屬意外，連他自己都沒料到。
「小人之言」——他說這一切，都是有人在你我之間挑撥。
項羽(心聲): 「好一張嘴。字字服軟，句句撇清。」
帳中所有人都在看你。

:: label probe
劉邦頭垂得更低，答得卻滴水不漏。
劉邦: 「所以遣將守關者，備他盜之出入與非常也。日夜望將軍至，豈敢反乎！」
防盜賊，不防你。和項伯帶回來的話，一字不差。
項羽(心聲): 「排練過的。」
你盯著他半晌，忽然覺得無趣——一個彎著腰把說辭背得滾瓜爛熟的人，你連跟他計較的興致都提不起來。
項羽: 「……罷了。」
@set 席間起疑 = true

@goto after_apology

:: label after_apology

:: if 說出曹無傷
話一出口，帳中靜了一瞬。
你看見劉邦眼裡極快地閃過一絲什麼——快得像沒有發生，隨即又是滿臉惶恐的賠笑。
帳外侍立的張良，垂下了眼。
你只是覺得——我項籍行事，光明磊落，不屑藏著掖著。是你的人賣了你，不是我項籍疑你。
你不知道，你隨口的一句話，已經注定了一個人的死。以及，從此再不會有第二個「曹無傷」向你傳遞任何消息。
:: else
你把那個名字嚥了回去。
不是深謀遠慮——只是覺得，一個賣主求榮的小人，提他的名字，髒了你項籍的嘴。
帳外侍立的張良，眼觀鼻，鼻觀心。漢營之中，那根刺還埋著。
:: endif

項羽: 「今日既來，便是客。設宴！」
項王即日因留沛公，與飲。
@wait 800
入席。
你和叔父項伯，東嚮坐——面朝東，帳中最尊的位置。
亞父范增，南嚮坐，次之。
劉邦，北嚮坐——那是臣子的座次。
張良，西嚮侍——連坐都沒得坐，是「侍」。
項羽(心聲): 「他既然口口聲聲稱臣，那就照臣子的規矩坐。」
劉邦在臣子的位置上坐下了，神色如常，甚至帶著笑。
你很滿意。
你沒有注意到，亞父看著這個座次，眉頭鎖得死緊——把心腹大患當部下款待，天下沒有這樣的宴席。
