此後的事，史書寫了整整四年。
@bg xianyang_fire.png fade=1500
你引兵西屠咸陽，殺子嬰，燒秦宮室，火三月不滅。

:: if 降卒處置 == "坑殺"
新安的二十萬，咸陽的大火。關中人對你的恨，就此刻入骨髓。後來劉邦還定三秦，秦人簞食壺漿以迎。人心這筆帳，是在這裡輸掉的。
:: endif
有人勸你都關中以霸天下，你說——「富貴不歸故鄉，如衣繡夜行，誰知之者！」
你分封十八路諸侯，自立為西楚霸王，都彭城。
你放逐義帝，又使人追殺於江中。
然後，諸侯一個接一個地反了。
帶頭的，正是那個在你宴席上彎腰稱臣、藉口如廁溜走的漢王。
@wait 1500
@bg pengcheng_battle.png fade=1200
彭城，你三萬破他五十六萬，漢卒十餘萬人被擠落睢水，水為之不流——你贏了。
滎陽、成皋，拉鋸經年。
陳平的反間計來了。你疑了亞父，奪了他的權。老人說——「天下事大定矣，君王自為之！」辭官東歸，背疽發作，死在半路。

:: if 范增信任 >= 2
你曾經那樣信過他。鴻門帳中，他舉玦的手，你至今記得。可你終究還是疑了他，只因一個外人的反間計。
:: else
鴻門宴上你不聽他，滎陽軍中你疑了他。這個為項家謀劃到七十五歲的老人，到死都沒等到你再叫他一聲亞父。
:: endif
鴻溝議和,，中分天下。你引兵東歸，他背約追擊。
@bg gaixia_night.png fade=2000
然後，垓下。
@wait 2000
夜。
你的十萬楚軍，被漢軍與諸侯兵重重圍住。兵少，食盡。
夜半，四面的漢營裡，忽然響起了歌聲。
楚歌。是楚地的歌。四面八方，全是。
項羽: 「漢皆已得楚乎？是何楚人之多也！」
@show 虞姬 center sad
帳中，虞姬為你披上大氅。你起身，飲酒，看著這個跟了你八年的女人，和帳外那匹跟了你八年的烏騅馬。
你這一生不曾服過誰，不曾輸過誰，此刻卻唱出了那首歌——
項羽: 「力拔山兮氣蓋世，時不利兮騅不逝。」
項羽: 「騅不逝兮可奈何——虞兮虞兮奈若何！」
歌數闋，美人和之。
你哭了。項王泣數行下。
左右皆泣，莫能仰視。
@hide 虞姬 fade=1500
@wait 2000
@bg gaixia_breakout.png fade=1200
是夜，你率八百餘騎潰圍南出，渡淮，迷失道。
田父紿曰——「左。」左，乃陷大澤中。
連一個種田的老人，都要騙你。
至東城，身邊只剩二十八騎。追兵數千。
項羽: 「吾起兵至今，八歲矣。身七十餘戰，所當者破，所擊者服，未嘗敗北，遂霸有天下。」
項羽: 「然今卒困於此。此天之亡我，非戰之罪也！」
天之亡我，非戰之罪。
你又說了一遍。像是說給二十八騎聽，又像是說給自己聽。
@wait 1500
@bg wujiang_shore.png fade=1500
於是,，烏江。
@show 亭長 center normal
烏江亭長檥船岸邊，等著你。全烏江，只有這一條船。
亭長: 「江東雖小，地方千里，眾數十萬人——亦足王也！」
亭長: 「願大王急渡！今獨臣有船，漢軍至，無以渡！」
江水滔滔。對岸，就是江東。

:: if 少年志向 == "名震天下"
你想起會稽江畔那個看著始皇車駕的少年。他要天下人記住項籍的名字——如今天下人都記住了。可他沒有想過，名字被記住的方式，有很多種。
:: elif 少年志向 == "取而代之"
「彼可取而代也。」你真的取而代之了——西楚霸王，政由羽出。可那個位子你只坐了四年，就坐到了這條江邊。
:: else
你當年起兵，是為了替楚國報仇。秦亡了，仇報了——可你腳下這條江，如今在替誰擋著誰？
:: endif
