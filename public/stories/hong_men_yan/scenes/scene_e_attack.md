天亮了。
四十萬對十萬。你甚至不需要計謀。
楚軍如潮水漫過霸上。漢軍的壁壘,撐了不到半日。
@wait 1500
亂軍之中,劉邦的下落有兩種說法。
有人說,沛公死於戲水之畔,死時身邊只剩十餘騎。
也有人說,他棄軍換裝,遁入芒碭山中——當年他做亭長時押送刑徒,也是逃進了那座山。從此,再無音訊。
張良不知所終。樊噲戰死於轅門,屍身伏在主公的車轍上。
@wait 2000

:: if 范增信任 >= 1
范增站在你身側,看著霸上的煙。
范增: 「大王這次,聽了老臣的話。」
但他的眉頭沒有鬆開。
范增: 「殺一個劉邦,容易。接下來——收關中的人心,難。」
:: else
范增站在你身側,一言不發。
仗是打贏了。可你是因為聽了他「急擊勿失」的謀,還是單純因為怒火燒到了頭頂?他分得出來。
謀士最怕的,不是主公不聽勸——是主公做對了事,卻是出於錯的理由。因為下一次,同樣的怒火,會燒出完全相反的決定。
:: endif
@wait 1500

:: if 降卒處置 == "坑殺"
入關之後,你很快嘗到了另一種滋味。
關中父老閉門,道路無人,簞食壺漿無人出——新安城南的二十萬白骨,秦人沒有忘。
你可以殺敗一切軍隊,卻沒有辦法命令一個老人對你笑。
:: endif
史書上,將不會有「鴻門宴」這三個字。
只有「戲西一戰」,和又一次的伏屍百萬。
@wait 2000
你用最直接的方式,解除了那個威脅。范增說的「急擊勿失」,你做到了——從純粹的兵略上說,這也許是對的。
但接下來呢?
分封諸侯,人人畏你而不服你。義帝還在,懷王之約還在——「先入咸陽者王之」的人,被你殺了。天下人都看在眼裡。
刀兵能贏下每一場戰役。
可是坐天下,靠的從來不是戰役。
這一次,沒有劉邦了。
可是「下一個劉邦」——那個懂得忍、懂得等、懂得收人心的人——永遠會有。
到那時,你會變嗎?
@wait 2500
