@bg hangu_pass.png fade=800
函谷關到了。
關門緊閉。城樓上，守軍的旗——不是秦旗。
是漢字旗。劉邦的兵。
探馬飛報——沛公已破咸陽。秦王子嬰素車白馬，繫頸以組，降於軹道之旁。
你在馬上，不發一語。
項羽(心聲): 「鉅鹿是誰打的？秦軍主力是誰滅的？諸侯是誰召集的？」
@camera zoom=1.2 x=0 y=0 duration=500
項羽(心聲): 「他劉邦，趁我與章邯血戰之時，撿了一座空咸陽！」
@camera-reset
你大怒，使當陽君等強攻函谷關。關破，大軍長驅直入，駐於戲西、新豐鴻門。
此時，沛公軍霸上，與你相距四十里。
@bg hongmen_camp.png fade=1000
@wait 1200
@bg hongmen_camp_night.png fade=1000
@se se_horse_gallop.mp3
當夜，有人求見——沛公麾下左司馬，曹無傷的密使。
使者伏在地上，一字一句：
「沛公欲王關中，使子嬰為相，珍寶盡有之。」
帳中死一般地靜。
欲王關中。使子嬰為相。珍寶盡有之。
每一個字，都往你燒著的那把火上澆油。

?? choice
- text: 拍案而起:「旦日饗士卒，為擊破沛公軍！」
  set: { 函谷之怒: "立擊" }
- text: 壓下火，先派探子去霸上查證，再作打算
  set: { 函谷之怒: "查證" }
- text: 把密使晾在一旁，先召亞父來商議
  set: { 函谷之怒: "問增" }
??

:: if 函谷之怒 == "立擊"
@set 怒氣 += 2
@show 項羽 center angry
@se se_heavy_thud.mp3
@shake 8 duration=500
項羽: 豈有此理！
@hide 項羽
命令當場就下去了。犒賞三軍，天亮開戰。
帳外將士歡聲雷動——跟著霸王，仗從來沒有輸過。
你甚至沒有問那個使者一句——曹無傷此人，為何要賣他的主公？他說的，句句是真？
你不需要問。你已經怒了。怒了，就要有人付出代價。
:: elif 函谷之怒 == "查證"
@set 怒氣 += 1
@set 曾經查證 = true
你捏著案角，把怒火嚥了回去，先遣探子連夜奔霸上。
天未亮，探子回報——沛公確實封了秦宮府庫，秋毫無所取，還軍霸上，約法三章，秦人爭獻牛羊酒食。
項羽(心聲): 「不取財，不掠民……他在收買人心。那函谷關的守軍，又作何解釋？」
你越想越不對。一個貪財好色的亭長，進了咸陽卻分文不取——這比「珍寶盡有之」更讓你心底發寒。
可是寒意轉瞬就被怒火蓋過去了。命令終究下了——旦日饗士卒，為擊破沛公軍！
:: else
@set 怒氣 += 1
@set 范增信任 += 1
你按住怒火，先召了范增。
@show 范增 center normal
老人聽完密報，捻著鬚。半晌，只問了一句——「大王注意到了嗎？曹無傷說『珍寶盡有之』——可探報都說，沛公封庫還軍，分毫未動。」
項羽: 「小人之言，誇大難免。要緊的是——他想王關中！」
范增看了你一眼，那眼神像是還有話，但他只是躬身——「擊之，老臣無異議。」
@hide 范增 fade=400
命令下了——旦日饗士卒，為擊破沛公軍！
:: endif
@wait 1500
當是時，
項王兵四十萬，號稱百萬，在新豐鴻門。
沛公兵十萬，號稱二十萬，在霸上。
四比一。你不必用任何計謀，天亮之後，平推過去，霸上就是一片焦土。
劉邦的性命，此刻就懸在你的一念之間。
