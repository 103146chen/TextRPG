夜。中軍帳。
@show 范增 center urgent
范增又來了。七十歲的老人，平生好奇計，被你尊為「亞父」。
這一次，他把話說得比誰都重。
范增: 「沛公居山東時，貪於財貨，好美姬。」
范增: 「今入關——財物無所取，婦女無所幸。」
范增: 「此其志不在小！」
@hide 范增
@show 范增 center-big urgent
他往前一步，聲音壓低，卻字字如錘。
范增: 「吾令人望其氣，皆為龍虎，成五采——此天子氣也！」
范增: 「急擊勿失！」
@hide 范增 fade=600
帳中燭火被風壓得一矮。
一個貪財好色的人，忽然不貪財、不好色了。亞父說，這比什麼都可怕——因為他想要的，是比財貨美姬大得多的東西。

?? choice

  goto: after_fanzeng
- text: 「一個亭長出身的老兵痞，能有什麼大志？」

- text: 「管他志在哪裡，明日一戰，都成灰燼」

:: label after_fanzeng

:: if 亞父之言 == "深信"
@set 范增信任 += 2
你點了頭。亞父眼中閃過一絲寬慰。
范增輔佐你以來，你第一次覺得，這老人看人的眼光，也許真的比你的戟還準。
「財物無所取，婦女無所幸」——一個能對到手的咸陽忍住不伸手的人，忍功比什麼都可怕。
你想起了那個詞——忍。你這一生，最不會的就是這個字。
:: elif 亞父之言 == "輕蔑"
你笑出了聲。
劉邦是什麼人？沛縣一個亭長，四十八歲才起兵，見了你要陪笑，論兵不如你，論力更不如你。
范增盯著你，那眼神不像在看一個霸王，像在看一個孩子。
范增: 「大王……老臣說的不是他這個人，是他背後的東西。」
你揮揮手，讓他退下了。
有些話，要等到很多年後的垓下，你才會想起。
:: else
@set 怒氣 += 1
你把杯中酒一飲而盡。
項羽: 「亞父，你們謀士就是想得太多。天子氣？我項籍打了八年仗，只信一樣東西——」
你拍了拍案上的戟。
范增退出帳外時，你聽見他低低嘆了一口氣——「大王只信刀兵。可奪天下靠刀兵，坐天下，靠的從來不是。」
你沒有聽進去。
:: endif
@wait 1500
夜更深了。
四十里外的霸上，漢營燈火寥落。你想像著天亮之後，那些燈火將一盞一盞熄滅。
你不知道的是——
就在此刻，你軍中有一騎快馬，悄悄出了轅門，正連夜馳向霸上。
馬上的人，是你的叔父，左尹項伯。
