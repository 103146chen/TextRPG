酒過三巡。
帳中觥籌交錯,笑語晏晏。劉邦頻頻舉杯,姿態放得極低;你喝得痛快,鉅鹿以來,難得這樣鬆快的一日。
@show 范增 right urgent
南面的席上,亞父一直沒有動筷。
他的眼睛,一次一次望向你。
你舉杯,他望著你。你放杯,他還望著你。
然後你看見——他抬起手,把腰間佩著的那塊玉玦,舉了起來。
玉玦。玦者,決也。
一次。
兩次。
三次。
范增數目項王,舉所佩玉玦以示之者三。
老人的眼神像刀子——動手。現在。就在席上。錯過今日,再無來日。
你的手,就放在劍柄旁邊。帳外都是你的武士,一聲令下,劉邦這一百多人,一個也走不出鴻門。
@wait 1500

  goto: scene_e_kill
- text: 別開眼,舉杯一飲而盡——他已稱臣,殺之不武

- text: 舉杯敬向劉邦,把亞父的目光擋在杯影之外
  set: { 舉玦回應: "迴避" }

:: label after_jue

:: if 舉玦回應 == "默然"
你別開了眼。
項羽(心聲): 「他北面稱臣,親身來謝。此時殺他,天下人怎麼說項籍?設宴誘殺一個伏低做小的人?」
項羽(心聲): 「要殺,也該堂堂正正,陣前殺。」
項王默然不應。
史書後來就是這麼寫的——五個字,寫盡了你的一生。
:: else
@set 范增信任 -= 1
你舉杯,朝著劉邦朗聲一笑,敬酒。
用一個熱絡的動作,把亞父的目光擋在了杯影之外。
劉邦連忙起身回敬,袖口都在抖——也不知是真怕,還是演得好。
南面的席上,那塊玉玦,終於垂了下去。
:: endif
@hide 范增 fade=600
@wait 1200
范增起身,出帳。
你沒有在意——老人家酒量淺,出去透透氣罷了。
你聽不見帳外的低語。後來你才知道,他攔住了你的堂弟項莊,說的是:
「君王為人不忍。若入前為壽,壽畢,請以劍舞,因擊沛公於坐,殺之。」
「不者,若屬皆且為所虜!」
@wait 1200
@show 項莊 center normal
項莊入帳,上前敬酒。壽畢,朗聲道:
項莊: 「君王與沛公飲,軍中無以為樂,請以劍舞!」
項羽: 「諾。」
項莊拔劍起舞。
劍光在帳中游走。一圈,一圈——每一圈,都往劉邦的席前偏過去一分。
@show 項伯 left earnest
忽然,你的叔父項伯也站了起來。
項伯: 「一人舞劍何趣?老夫來與項莊對舞!」
項伯亦拔劍起舞,常以身翼蔽沛公——像鳥張開翅膀那樣,一次一次,用身子擋在劉邦面前。
莊不得擊。

:: if 對項伯起疑
項羽(心聲): 「昨夜他深夜從何處來——此刻,我有答案了。」
你看著叔父的背影,那把年邁的劍,舞得漏洞百出,卻擋得滴水不漏。
可你什麼也沒有說。
:: endif

- text: 由他們舞——一個要殺,一個要護,你倒想看看天意向著誰
  set: { 劍舞應對: "看天意" }

- text: 皺眉盯著叔父——他今日,為何處處攔著項莊?
  set: { 劍舞應對: "疑項伯" }
  goto: after_dance
??

:: label after_dance

:: if 劍舞應對 == "叫停"
你抬起手。
項羽: 「舞得夠了。都坐下。」
兩柄劍同時收住。項莊滿頭是汗,退回席位時,不敢看南面。
亞父在席上,閉了閉眼。
一場殺局,被你一句話拆了——你自己,卻只當是止住了一場助興的舞。
:: elif 劍舞應對 == "看天意"
你斜倚著,饒有興味地看。
一柄劍要殺,一柄劍要護。殺的是你帳下的刀,護的也是你項家的人——這局棋,兩邊都是你的子,你卻誰也不幫。
把生死當成戲看。這很項羽。
天意沒有給出答案。答案在帳外——正在趕來的路上。
:: else
@set 對項伯起疑 = true
你的眉頭越皺越緊。
項莊的劍路,你看得懂——那不是舞,是殺招。而叔父的每一步,都精準地踩在殺招前面。
項羽(心聲): 「他在護劉邦。我項家的左尹,在我項家的宴席上,護一個外人。」
可你依然沒有出聲。動了項伯,就是承認這席上有殺局;承認有殺局,你項籍的臉面往哪裡放?
:: endif
@hide 項莊 fade=400
@hide 項伯 fade=400
@wait 800
就在這時——
帳外一聲巨響,一名衛士仰面摔了進來。
