@textcfg speed=36
@show 秦伯 center-big thinking
@show 燭之武 left calm

旁白: 秦伯在等你說下去。

旁白: 案上的燈燒短了一截。你有半炷香的時間，把一件事說清楚：

@wait 700
@camera zoom=1.15 duration=800

旁白: **鄭國亡了，秦國得到什麼。**

@wait 900
@camera-reset

旁白: 這件事可以從很多地方切進去。你只能選一個——第一刀切錯了地方，後面就都是廢話。

@wait 700

:: label after

:: if 切入角度 == "地理"
燭之武[calm]: 「越國以鄙遠，君知其難也。」

@wait 900

旁白: 越過別的國家，把遙遠的土地當作自己的邊邑——這件事有多難，您比誰都清楚。

@wait 800
@camera zoom=1.2 duration=800

燭之武: 「秦在西，鄭在東。從雍城到新鄭，一千二百里。」

燭之武: 「這一千二百里中間，隔著什麼？」

@wait 900
@show 秦伯 center-big thinking

旁白: 秦伯沒有回答。

旁白: 他不必回答。中間隔著的是晉國——這件事，帳裡每一個人都知道。

@wait 900
@camera-reset

燭之武: 「鄭國若歸了秦，君上的糧要從哪裡運？君上的兵要從哪條路換防？出了事，君上的令要走幾天才到得了？」

@wait 800

燭之武: 「而這幾天裡，這塊地是誰在替君上看著？」

@wait 1000
@se se_cup_down.mp3

旁白: 秦伯的手指在案上輕輕敲了一下。

@wait 700

燭之武(心聲): 他在算。

燭之武(心聲): **一個人開始算的時候，就已經不在打仗了。**

:: elif 切入角度 == "鄰厚"
燭之武[calm]: 「焉用亡鄭以陪鄰？」

@wait 800

燭之武: 「鄰之厚，君之薄也。」

@wait 1000
@show 秦伯 center-big wary

旁白: 秦伯的眼睛動了一下。

@wait 700

秦伯[wary]: 「鄰。」

@wait 600

燭之武: 「君上與晉侯共圍此城。城破之後，鄭國的地，是往北去，還是往西去？」

@wait 800

燭之武: 「往北，接的是晉國的境。往西，隔著晉國的境。」

@wait 900

燭之武: 「這塊地只有一個地方去得了。」

@wait 800
@camera zoom=1.2 duration=900

燭之武: 「君上帶著兵、耗著糧、走了一千二百里，替鄰國把邊界往東推了一寸。」

燭之武: 「鄰國厚一寸，秦國就薄一寸。」

@wait 1000
@camera-reset

旁白: 帳裡很安靜。

@wait 600

燭之武(心聲): 這句話有點重。

燭之武(心聲): 重在它不只說了「秦國得不到」，還說了「晉國得到了」。

@wait 700

燭之武(心聲): **我提早把晉國放到了桌子上。他若接得住，後面就順；接不住，他會覺得我在挑撥。**

:: elif 切入角度 == "東道"
燭之武[calm]: 「若舍鄭以為東道主，行李之往來，共其乏困，君亦無所害。」

@wait 1000

旁白: 假如放過鄭國，讓它做您東方道路上的主人——秦國的使者往來經過，鄭國供給他們所缺的一切，對您並沒有壞處。

@wait 900
@show 秦伯 center-big thinking

秦伯[thinking]: 「東道主。」

@wait 700

旁白: 他把這三個字唸了一遍，像在秤它的重量。

@wait 800

燭之武: 「君上是要往東邊去的人。這一點，天下都看得出來。」

燭之武: 「往東去，要過境、要糧、要驛、要有人接應。」

@wait 800

燭之武: 「一座亡了的城，什麼也給不了君上。」

@wait 700

燭之武: 「一座活著、而且欠著君上一條命的城——年年都給得了。」

@wait 1000
@camera zoom=1.2 duration=800

旁白: 秦伯笑了一下。那是今晚他第一次笑。

@wait 700

秦伯: 「你要寡人留一個活的鄭國，替寡人看著東邊的路。」

@wait 600

燭之武(心聲): 他懂了。而且他自己說出來了。

@camera-reset

:: else
@show 秦伯 center-big wary
燭之武: 「君上可還記得焦、瑕二城？」

@wait 900
@se se_cup_down.mp3

旁白: 秦伯放下杯子的動作，比剛才重。

@wait 700

秦伯[wary]: 「老丈。」

@wait 600

秦伯: 「你走了十二里路，冒著性命縋下城牆，坐到寡人帳裡來——第一件事是替寡人數舊帳？」

@wait 900

秦伯: 「你連鄭國的事都還沒說，就先說晉國的事。」

@wait 700

秦伯: 「你是在替鄭國求生，還是在替鄭國分我們的兵？」

@wait 1000
@show 燭之武 left normal

燭之武(心聲): 太快了。

燭之武(心聲): 這張牌是好牌——可是好牌要在對的時候出。

@wait 800

燭之武(心聲): 我還沒有讓他相信「亡鄭無益」，就先讓他看見「這人想拆散我們」。

@wait 700

燭之武(心聲): **離間之所以有用，是因為它聽起來像是替對方著想。**
燭之武(心聲): 一旦次序倒了，它就只剩下離間。

@wait 800

旁白: 你定了定神，還是把那三句話補了上去——越國以鄙遠，鄰之厚君之薄，舍鄭以為東道主。

旁白: 說得很完整。可是秦伯聽的時候，眼睛裡多了一樣剛才沒有的東西。

@wait 700
:: endif

@wait 900
@hide 燭之武
@show 秦伯 center-big thinking
@camera zoom=1.15 duration=900
@bgm bgm_doubt.mp3

旁白: 秦伯沉默了很久。

@wait 800

旁白: 久到帳外的更漏又響了一次。

@wait 900

秦伯[thinking]: 「你說的這些，寡人不是沒有想過。」

@wait 700

秦伯: 「可是寡人已經來了。三百乘車，一千二百里。」

@wait 600

秦伯: 「什麼都不做就回去——寡人要怎麼跟雍城的人交代？」

@wait 1000
@camera-reset
@show 燭之武 left sharp

燭之武(心聲): 來了。

@wait 700

燭之武(心聲): 他不是不信我。他是**已經信了，只差一個回去的理由**。

@wait 900

燭之武(心聲): 一個君主要撤兵，不能是因為「我算過了不划算」。

燭之武(心聲): 那太像認輸。

@wait 800
@camera zoom=1.25 duration=900

燭之武(心聲): 得讓他覺得——**繼續打下去，才是真正的危險。**

@wait 700

燭之武(心聲): 而那個危險，不在城裡。

@wait 800

燭之武(心聲): 在函陵。
