@textcfg speed=36

旁白: 三更三點。西牆。

旁白: 風是從北面來的，帶著河上的水氣。城堞的磚縫裡積著白天的露，摸上去比想像中冷。

@wait 700
@se se_rope_creak.mp3

旁白: 兩個守卒把繩子從絞盤上放下來，在你腰上繞了三圈，打了一個很緊的結。

@wait 600

旁白: 「大夫，」年輕的那個說，「這繩……有點舊。」

@wait 500

旁白: 「城裡最好的繩，都拿去綁滾木了。」年長的那個說。

@wait 700

燭之武: 「無妨。它只要撐一次。」

@wait 800
@camera zoom=1.2 y=8 duration=1000

旁白: 你扶著垛口坐上去，兩隻腳懸在外面。

旁白: 底下是黑的。看不見地，只看得見更遠的地方——氾水之南，一片散開的火點，像有人把一把星子撒在了地上。

@wait 900
@camera-reset
@bgm-stop fade=1500
@se se_wind_high.mp3

旁白: 夜縋而出。

@wait 1200
@bg wall_descend.png fade=1000
@camera vignette=0.5 duration=900

旁白: 下降的時候，人是轉的。

旁白: 你先看見城牆，再看見天，再看見城牆。繩子在腰上勒得很緊，勒得你想起很多不相干的事。

@wait 800

:: if 秦晉之隙 >= 1
燭之武(心聲): 那年冬天，一個人從鄭國的城門穿過去，沒有喝到一杯酒。

燭之武(心聲): 十九年後，他帶著兩個國家的軍隊回來了。

@wait 700

燭之武(心聲): 記仇的人可怕。可是記仇的人也有一個好處——

燭之武(心聲): **他一定也記得別人怎麼對不起他。而別人，不只鄭國一個。**

:: elif 姿態分寸 >= 1
燭之武(心聲): 「師必退」。

燭之武(心聲): 佚之狐憑什麼說得這麼滿？

@wait 700

燭之武(心聲): 他不是相信我。他是相信那件我在城牆上看見的事——

燭之武(心聲): 秦軍和晉軍，分開紮營。

:: elif 鄭伯之信 >= 2
燭之武(心聲): 那兩口井。

燭之武(心聲): 排隊的人裡有個婦人，抱著孩子，讓後面的人先打。她說她家還剩半甕。

@wait 700

燭之武(心聲): 她沒有得罪過晉侯。她連晉侯長什麼樣子都不知道。

@wait 600

燭之武(心聲): 我今夜要去替她說話，而她永遠不會知道。

:: else
燭之武(心聲): 第一句：認輸。

燭之武(心聲): 鄭國已經知道自己要亡了——先把這句說出來，秦伯才會放下心來聽下一句。

@wait 700

燭之武(心聲): 第二句：算帳。鄭亡了，秦得到什麼？

燭之武(心聲): 第三句……第三句要等他自己想起來。

@wait 600

燭之武(心聲): **話說得太滿，人就不信了。要讓他覺得，那個結論是他自己得出來的。**
:: endif

@wait 900
@se se_land_soft.mp3
@camera-reset
@bg wild_field_night.png fade=1000
@particles-stop

旁白: 腳碰到地的時候，你差點站不住。

旁白: 繩結鬆開，繩子往上收了回去，很快就縮進黑暗裡不見了。

@wait 800
@camera zoom=1.15 duration=900

旁白: 你回頭看了一眼。

旁白: 城牆在你上面，高得看不見頂。牆上沒有人探頭，也沒有人揮手。

@wait 700

燭之武(心聲): 進不去了。

燭之武(心聲): 這條路只有一個方向。

@wait 900
@camera-reset
@bgm bgm_night_tense.mp3

旁白: 你把衣襟整了整，把袖口的草屑撣掉。

旁白: 七十歲的人，走一里路要歇一次。從城牆到氾南的秦營，有十二里。

@wait 800

旁白: 你開始走。
