@textcfg speed=36

旁白: 十二里路，你走了兩個時辰。

旁白: 最後一里是沿著氾水的堤走的。水聲很大，大到你聽不見自己的腳步——也聽不見別人的。

@wait 700
@se se_torch_flare.mp3
@flash #ffddaa duration=300

旁白: 火把是忽然舉起來的。

@wait 500
@show 秦軍哨官 center normal
@camera zoom=1.15 duration=600

秦軍哨官: 「站住。」

@wait 600

旁白: 四五個人從堤下上來，把你圍在中間。他們沒有喊，動作很輕——這是老兵的規矩，夜裡不叫。

@wait 700

秦軍哨官: 「老丈，這裡是秦軍的營。你從哪裡來？」

@wait 800
@camera-reset

旁白: 火把離你的臉很近。你能感覺到那點熱。

旁白: 這是今晚的第一關。你怎麼說，決定了半個時辰之後，秦伯是用什麼心情看你走進帳裡。

@wait 700

?? choice
- text: 「鄭國使者，求見秦君。」
  set: { 秦伯戒心: 2, 自報身分: "使者" }
  goto: after
- text: 「亡國之臣，來替秦君說一件跟秦國有關的事。」
  set: { 秦伯戒心: 1, 姿態分寸: 1, 自報身分: "亡臣" }
  goto: after
- text: 「一個鄭國的老頭。城裡沒有糧了，我出來找活路。」
  set: { 秦伯戒心: 3, 自報身分: "投奔" }
  goto: after
- text: 「我來告訴秦君，這一仗打完，得地的不是秦國。」
  set: { 秦伯戒心: 1, 秦晉之隙: 1, 自報身分: "獻策" }
  goto: after
??

:: label after

:: if 自報身分 == "使者"
旁白: 哨官的手按在了劍柄上——不是要出鞘，是要讓你看見。

@wait 600

秦軍哨官: 「使者？兩軍圍城，城裡的使者半夜爬出來，是使者還是細作？」

@wait 700

燭之武: 「若是細作，我會挑一條沒有火把的路走。」

@wait 800

旁白: 他盯著你看了很久，最後把手放下了。

@wait 600

燭之武(心聲): 一個「使者」，意味著我代表鄭國。

燭之武(心聲): 代表鄭國，就等於代表「有所求」。

@wait 700

燭之武(心聲): ——秦伯會先把我當成來求他的人。這一層戒心，等一下要花力氣拆。

:: elif 自報身分 == "亡臣"
旁白: 哨官皺起眉。

@wait 500

秦軍哨官: 「亡國之臣？鄭國還沒亡。」

@wait 700

燭之武: 「圍了五天，城裡的井剩下一口。將軍是行伍出身，這個數目要算多久？」

@wait 800

旁白: 哨官沒有答話。他回頭跟身後的人低聲說了一句，那人轉身往營裡跑了。

@wait 700

燭之武(心聲): 「亡國之臣」四個字，把我從「來求你的人」變成了「已經沒什麼可求的人」。

燭之武(心聲): 沒有可求的人說的話，聽起來比較像真話。

:: elif 自報身分 == "投奔"
旁白: 有人笑了出來。

@wait 500

秦軍哨官: 「找活路找到轅門來？老丈，你走錯地方了。」

@wait 700

旁白: 他們搜了你的身，很仔細。袖子、衣襟、鞋底。搜完之後，把你帶到營門外的空地上等著。

@wait 800

旁白: 你在那裡站了半個時辰，沒有人給你水。

@wait 600
@show 燭之武 center bitter

燭之武(心聲): 我把自己說低了。

燭之武(心聲): 低到他們不必防我——**也不必聽我。**

@wait 700

燭之武(心聲): 一個逃難的老頭走進大帳，秦伯會賞他一碗粥，然後打發他走。

燭之武(心聲): 等一下我得先把自己說回來。這要多花很多力氣。

@hide 燭之武

:: else
旁白: 哨官愣住了。

@wait 700

秦軍哨官: 「……你說什麼？」

@wait 600

燭之武: 「我說，這一仗打完，鄭國的地在誰手裡。」

@wait 500

燭之武: 「將軍不必答我。將軍只要想一想：從這裡到雍城，要走幾天？從這裡到絳城，要走幾天？」

@wait 900

旁白: 哨官張了張嘴，沒有出聲。

@wait 700

旁白: 過了一會兒，他親自帶你往營裡走。一路上他沒有再問你任何問題。

@wait 600

燭之武(心聲): 這句話太重了。

燭之武(心聲): 重到連一個哨官都覺得，這件事不該由他來聽。

@wait 700

燭之武(心聲): ——但也重到，秦伯還沒見我，就已經知道我要說什麼了。

燭之武(心聲): **牌先掀了一張。等一下要更小心。**
:: endif

@wait 900
@hide 秦軍哨官
@bg qin_camp_inner_night.png fade=1000
@bgm bgm_planning.mp3

旁白: 你被帶進了營。

旁白: 秦軍的營和你在城牆上看見的一樣——整齊、安靜，甬道兩側的帳篷排得像刻出來的。

@wait 700

旁白: 你一路數著。左邊十七排，右邊十九排。糧車在西側，車轅一律朝西。

@wait 800
@camera zoom=1.2 x=-10 duration=900

燭之武(心聲): 車轅朝西。

燭之武(心聲): 隨時可以走。

@wait 900

燭之武(心聲): 一支準備長住的軍隊，車轅是朝內的。

燭之武(心聲): 秦伯……你自己心裡也沒有打算待很久，是不是？

@wait 800
@camera-reset
@se se_tent_flap.mp3

旁白: 中軍大帳的門簾掀開了。

旁白: 裡面有燈。
