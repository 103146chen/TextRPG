@textcfg speed=36

旁白: 火把停在馬廄門口。來的人比你想的多。

旁白: 然後那些人分開，讓出一條路。

@wait 700
@se se_footsteps_single.mp3
@show 鄭伯 center humble
@camera zoom=1.15 duration=800

旁白: 走進來的是鄭伯。

@wait 800

旁白: 他站在草料堆和馬槽之間，那身衣服在這個地方顯得很不合適。他大概三十年沒進過馬廄了。

@wait 600

鄭伯[humble]: 「燭之武。」

@wait 700
@camera-reset
@show 燭之武 left normal

旁白: 你放下鍘刀，拱了拱手。

@wait 500

鄭伯: 「城外的事，你知道了。」

鄭伯: 「寡人要你出城，見秦君。」

@wait 900
@bgm bgm_tension.mp3

旁白: 這句話從國君嘴裡出來，中間沒有一個「請」字。

@wait 700
@camera zoom=1.2 x=-12 duration=800

旁白: 你抬起頭來。

旁白: 你已經想了一整夜，可是真到這一刻，你發現自己要說的第一句話，跟你想的不太一樣。

@wait 600

?? choice
- text: 「臣之壯也，猶不如人；今老矣，無能為也已。」
  set: { 鄭伯之信: 1 }
  goto: 鄭伯之答
- text: 「君上，臣是圉正。圉正見秦君，秦君會怎麼想鄭國？」
  set: { 鄭伯之信: 2, 秦伯戒心: -1 }
  goto: 鄭伯之答
- text: 「三十年了。君上今天才知道臣會說話。」
  set: { 懷才不遇: 1, 鄭伯之信: -1 }
  goto: 鄭伯之答
- text: 「臣去。什麼時候動身？」
  set: { 鄭伯之信: 1, 姿態分寸: -1 }
  goto: 直接答應
??

:: label 直接答應
@camera-reset

旁白: 鄭伯愣了一下。他準備了一路的話，一句都沒用上。

@wait 700

鄭伯[humble]: 「……你不問問，寡人為什麼今天才來找你？」

@wait 600

燭之武: 「城外有兩支軍隊，城裡有兩口井。臣問這個做什麼？」

@wait 800

旁白: 鄭伯看了你很久。

@wait 500

鄭伯: 「三更之後，西牆。」

@wait 700
@show 燭之武 left normal

燭之武(心聲): 我答得太快了。

燭之武(心聲): 快到他還沒有機會說出那句「是寡人之過也」——

@wait 700

燭之武(心聲): 而一個沒有低過頭的國君，是不會替我記住這一夜的。

@wait 800
@hide all
@goto 動身

:: label 鄭伯之答
@camera-reset
@hide 燭之武
@show 鄭伯 center humble

:: if 鄭伯之信 <= 0
旁白: 鄭伯的臉沉了下去。

旁白: 你看著他把那口氣忍回去——忍得很辛苦，可是他忍了。城外有兩支軍隊，他沒有別的辦法。

@wait 700

鄭伯: 「你說得對。」

鄭伯: 「寡人不能早用子。」

@wait 600

旁白: 他說這話的時候沒有看你。

:: elif 鄭伯之信 >= 2
旁白: 鄭伯沉默了一會兒。

@wait 600

鄭伯[humble]: 「你連這個都替寡人想到了。」

@wait 700

鄭伯: 「那就不是圉正去。寡人今日拜你為大夫——你是鄭國的使者。」

@wait 800

燭之武(心聲): ……他反應得比我想的快。

燭之武(心聲): 一個能在這個時候還聽得懂話的國君，事情就還有得談。

:: else
旁白: 鄭伯沒有動氣。

旁白: 他站在那裡，聽完了你這句「無能為也已」，然後很慢地點了點頭。

:: endif

@wait 900
@camera zoom=1.2 duration=800
@bgm bgm_thinking.mp3

鄭伯[humble]: 「吾不能早用子，今急而求子，是寡人之過也。」

@wait 1000

旁白: 馬廄裡沒有人說話。

旁白: 三十年。你等的不是這句話，可是這句話還是在你胸口裡撞了一下。

@wait 900
@camera-reset
@show 鄭伯 center normal
@bgm bgm_tension.mp3

旁白: 然後他往前走了一步。

@wait 600

鄭伯: 「然鄭亡，子亦有不利焉。」

@wait 1000
@show 燭之武 left bitter
@camera zoom=1.15 x=-10 duration=800

燭之武(心聲): ……好一個「子亦有不利焉」。

@wait 700

燭之武(心聲): 前一句是認錯，後一句是提醒。認錯是給我的臺階，提醒是給我的繩子。

@wait 700

燭之武(心聲): 他到底還是國君。他知道光靠一句道歉，換不動一個等了三十年的人。

@wait 800

燭之武(心聲): 那麼——我要不要走上這個臺階？

@camera-reset
@wait 600

?? choice
- text: 「許之。」——事已至此，鄭亡則無所謂利與不利
  set: { 鄭伯之信: 1 }
  goto: 動身
- text: 「臣去。但君上要記得，今夜是君上開的口。」
  set: { 鄭伯之信: 1, 懷才不遇: 1 }
  goto: 動身
- text: 「君上說臣亦有不利。可臣已經七十了，還能不利到哪裡去？」
  set: { 懷才不遇: 2 }
  goto: 堅辭
??

:: label 堅辭
@bgm bgm_unused.mp3
@show 燭之武 center bitter
@camera zoom=1.25 duration=900

旁白: 你說完了，才發現自己的聲音那麼平。

@wait 700

燭之武: 「臣之壯也，猶不如人。那時候臣還跑得動，還想得快，還肯把話遞進宮裡去。」

燭之武: 「沒有人聽。」

@wait 800

燭之武: 「今老矣。」

@wait 600

燭之武: 「無能為也已。」

@wait 1000
@camera-reset
@hide 燭之武
@show 鄭伯 center anxious

旁白: 鄭伯站在那裡，很久很久。

旁白: 他沒有發怒。他只是忽然變得很老，像一個知道自己已經沒有下一句話可說的人。

@wait 900

鄭伯[anxious]: 「……寡人知道了。」

@wait 700
@hide 鄭伯
@se se_footsteps_many.mp3

旁白: 火把一支一支退出馬廄。最後一支光走的時候，你聽見自己的呼吸。

@wait 900
@goto e_不出

:: label 動身
@camera-reset
@hide all
@bgm bgm_hurry.mp3
@bg zheng_street_night.png fade=900

旁白: 「三更之後，西牆。」

@wait 600

旁白: 鄭伯走了。你把最後一槽草料鍘完，拍了拍手上的碎屑。

@wait 700

旁白: 那匹老馬在暗處看著你。

@wait 600

燭之武(心聲): 我這一生走過最遠的路，是從馬廄到城牆。

@wait 800

燭之武(心聲): 今天晚上，要走得更遠一點。
