魯僖公二十三年，冬。鄭國，新鄭城西的馬廄。
你叫燭之武。這一年你六十三歲。
鄭國的官制裡，有一個位子叫「圉正」——管馬的。管馬的人要記得每一匹馬的脾氣、齒齡、蹄鐵鬆緊，要在天亮前把草料鍘好。
你做了十九年。
@wait 800
@se se_horse_snort.mp3
@wait 500
燭之武: 「別踢。今天的豆餅少了，不是我要剋你。」
燭之武(心聲): 城裡在傳，晉國那位流亡的公子過境了。
那位公子姓姬，名重耳。晉獻公的兒子，在外面漂泊已了十九年，和你當圉正的年數一樣長。
@bg zheng_gate.png fade=800
@bgm bgm_cold_court.mp3
你抱著一捆草料經過城門內側的迴廊時，聽見裡面有人在說話。
@bg zheng_court_inner.png fade=600
@show 鄭伯 center arrogant
@camera zoom=1.15 x=0 y=-4 duration=700
鄭伯[arrogant]: 「一個逃了十九年的人，走到哪裡都要人擺酒？寡人的糧倉是替落難者開的？」
說話的是鄭文公，你的國君。
站在他對面的是大夫叔詹。你只看得見他的背影，那個背影躬得很低。
@hide 鄭伯
「臣聞天之所啟，人弗及也。晉公子有三焉，天其或者將建諸？君其禮焉。」
叔詹說完，殿裡靜了一會兒。
@se se_door_close.mp3
然後是一聲很輕的、關門的聲音。
@wait 600
燭之武(心聲): 沒有酒，沒有食，沒有一句客套。晉國的公子從鄭國的城門穿過去，像穿過一條無人的巷子。
燭之武(心聲): 而我抱著一捆草料，站在迴廊的陰影裡。
@camera-reset
@bgm bgm_thinking.mp3
你今年六十三歲。雖從未參與朝堂政事，對基本應對進退之禮仍略知一二。
文公此舉，有失禮數。

:: if 重耳之事 == "附和"
@bg zheng_corridor.png fade=500
你在迴廊盡頭追上叔詹。他停下來，看了看你的手——那雙手上還沾著草屑。
「你也懂這個？」
燭之武: 「臣不懂。臣只知道馬。」
燭之武: 「可是餓過的馬，會記得誰餵過牠，也會記得誰沒餵。」
叔詹笑了一下，那笑很短。
「圉正說得比殿上好。」他說，「可惜殿上不聽圉正說話。」
:: elif 重耳之事 == "進言"
@bg zheng_corridor.png fade=500
你把草料放在階下，托門吏遞了一句話進去。
那句話是：「馬廄裡養不出千里馬——千里馬是在別人家長大的，將來回來的時候，牠記得誰給過草。」
@wait 700
@se se_door_close.mp3
門吏出來的時候，臉色不太好看。
「君上說，」他頓了頓，「一個圉正，管好你的馬。」
@show 燭之武 center bitter
@camera zoom=1.2 duration=600
燭之武(心聲): 管好你的馬。
燭之武(心聲): ——好。
@camera-reset
@hide 燭之武
:: elif 重耳之事 == "記下"
你沒有走進去。
你把草料抱回馬廄，鍘好，分槽，一匹一匹餵過去。做完這些的時候，天已經黑了。
然後你在土牆上刻了一道很淺的痕。
燭之武(心聲): 記著。這一天，鄭國得罪了一個人。
燭之武(心聲): 得罪人不要緊，要緊的是——那個人會回來。
:: else
@bg zheng_road_night.png fade=800
@bgm bgm_night_quiet.mp3
三更之後，你扛著兩袋豆餅走上驛道。
你沒有見到那位公子。你把袋子放在驛亭的石階上，回頭就走。
你並非為了什麼。只是覺得，走了那麼遠的路，馬總該吃點東西。
@wait 700
燭之武(心聲): 何況——馬會記得。人也會。
:: endif
@wait 800
@bg zheng_stable.png fade=900
@bgm-stop fade=1000
那一年冬天過去了。晉公子重耳離開鄭國，往南去了楚國。
後來的事，你是很多年以後才在市集上聽人說起的：
他回國了，做了晉侯。
@wait 500
而你，還在鍘草。
