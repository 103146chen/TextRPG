@textcfg speed=36
圍城的第五天，鄭伯召群臣議事。
你不在議事的名單上。你在殿外的階下，替一位大夫牽馬。
@wait 600
@show 鄭伯 center anxious
鄭伯[anxious]: 「秦、晉兩軍在外，城中粟不足支一月。諸卿有以教寡人？」
@wait 700
殿裡靜了很久。
有人說要死守，有人說要遣使求和。
求和的話一出口，就有人問：向誰求？晉侯要的是這口氣，秦伯要的是什麼，誰知道？
@wait 800
然後有一個人開口了。
@hide 鄭伯
@show 佚之狐 center urgent
@camera zoom=1.15 duration=700
@bgm bgm_tension.mp3
佚之狐[urgent]: 「國危矣。」
@wait 700
佚之狐: 「若使燭之武見秦君，師必退。」
@wait 900
@camera-reset
@se se_murmur.mp3
殿外的階下，你正把韁繩繞在木樁上。
那個名字傳出來的時候，你的手停住了。
@wait 800
@show 燭之武 right normal
@camera zoom=1.2 x=12 duration=800
燭之武(心聲): ……誰？
@wait 600
燭之武(心聲): 三十年了。這座宮裡從來沒有人在殿上說過我的名字。
@camera-reset
殿裡有人問：「燭之武是誰？」
@wait 500
佚之狐答得很慢：

:: if 曾諫鄭伯 >= 2
佚之狐: 「圉正。三十年前君上還沒即位的時候，他就在了。」
佚之狐: 「當年晉公子過鄭，他託人遞過一句話進來。那句話說：千里馬是在別人家長大的，回來的時候，牠記得誰給過草。」
@wait 700
佚之狐: 「當時無人理會。」
@wait 600
佚之狐: 「今日馬回來了，就在函陵。」
:: elif 曾諫鄭伯 == 1
佚之狐: 「圉正。管馬的。」
佚之狐: 「當年晉公子過鄭，叔詹諫而不聽。事後只有這人在迴廊上跟叔詹說，那話說得對。」
@wait 600
佚之狐: 「叔詹跟臣說過這件事，說了不只一次。」
:: else
佚之狐: 「圉正。管馬的。」
@wait 500
殿裡有人笑了一聲——很輕，但是聽得見。
@wait 600
佚之狐: 「諸位笑什麼？」
佚之狐: 「秦、晉的甲士就在城外。這時候還笑得出來的人，才真令人發笑。」
@wait 700
佚之狐: 「臣不認得他多深。臣只知道，這個人在城牆上站了三天，把兩邊的營看完了。」
佚之狐: 「城裡站在牆上看營的，只有他一個。」
:: endif
@wait 900
@hide 佚之狐
@show 鄭伯 center anxious
@bgm bgm_doubt.mp3
鄭伯[anxious]: 「……一個圉正。」
@wait 700
你在殿外，隱約聽見自己的國君用那樣的語氣念出自己的職稱。
@wait 600
鄭伯: 「諾。」
@wait 500
一個字。他答應了。
@hide 鄭伯
@wait 800
@bg zheng_stable_night.png fade=900
@bgm bgm_night_quiet.mp3
那天晚上，你照舊鍘草、分槽、餵馬。
你知道有人會來。你不知道的是，你要怎麼開口。
@wait 800
@show 燭之武 center normal
@camera zoom=1.15 duration=700

?? choice
- text: 「三十年不問，如今兵臨城下才想起我。」——先把這口氣理順
  set: { 懷才不遇: 1 }
  goto: after
- text: 反覆想的是秦營。地形、糧道、秦伯的年紀、他要什麼
  set: { 秦國之利: 1 }
  goto: after
- text: 想的是城裡那兩口見底的井
  set: { 鄭伯之信: 1 }
  goto: after
- text: 想的是佚之狐——他為什麼記得我？
  goto: after
??

:: label after
@camera-reset

:: if 懷才不遇 >= 3
燭之武(心聲): 三十年。三十年他們不用我，是因為不需要。
燭之武(心聲): 今天需要了。
@wait 600
燭之武(心聲): 我可以去。我也可以讓他親口聽見，什麼叫「無能為也已」。
:: elif 秦國之利 >= 1
燭之武(心聲): 秦伯今年六十有餘。他這一生打過的仗，沒有一場是白打的。
燭之武(心聲): 這樣的人不會為別人的恩怨跑一千里路。
@wait 700
燭之武(心聲): 他要的是好處。那就好辦了——
燭之武(心聲): 要恩怨的人不好說，要好處的人好說。因為好處可以算。
:: elif 鄭伯之信 >= 1
燭之武(心聲): 井要見底了。
燭之武(心聲): 城牆上的兵，一天只吃兩頓。有個孩子在市集口哭了半天，沒有人有力氣去哄他。
@wait 700
燭之武(心聲): 這些人沒有得罪過誰。晉侯那扇門，不是他們關的。
:: else
燭之武(心聲): 佚之狐。
燭之武(心聲): 我和他說過的話，加起來不到十句。
@wait 700
燭之武(心聲): 可是他在滿殿的人面前，把一個圉正的名字說了出來。
@wait 600
一個人肯替你賭上自己的信譽，豈能怠慢？
:: endif
@wait 900
@hide 燭之武
@bgm-stop fade=1200
@se se_footsteps_many.mp3
三更將盡的時候，馬廄外面有火把的光。
不只一支。
