要北伐,先得安定後方。
南方的部族屢屢起事——雍闓、孟獲先後聚眾響應。不平定南方,你便不能放心出兵。
建興三年春,你親自率軍南征。
@wait 800
這條路,比你想像的還難走。
五月,你來到瀘水邊。瘴氣彌漫,水土陌生。涉水而過的隊伍,不少人沒能再回去。
你每天清點軍中的冊子。每一個名字,你都看一遍。
諸葛亮(心聲): 「他們從成都跟我出來的時候,還有家人在城門口送行。」
你站在瀘水邊,看著渾濁的河水。年少時你曾跟著叔父走過很長的路;如今,你成了那個帶著別人走路的人。
諸葛亮(心聲): 「這條路,走得很沉。」
@wait 1500
南方的部族首領孟獲被你的部將擒住了。將領們建議直接結案,以絕後患。
你卻把他放了。
你心裡明白，結了這一個容易,可結了之後,南方人心更不服,過幾年又會反。要的不是這一仗的勝負,是十年、二十年的安穩。
此刻,你心裡想的是什麼?

?? choice
- text: 兵者,不得已而用之。能少傷一個,就少傷一個
  set: { 渡瀘之念: "仁政" }
- text: 攻城為下,攻心為上。要他心服,蜀漢的南邊才能真正安穩
  set: { 渡瀘之念: "攻心" }
- text: 我比誰都不願走這一趟。可若不走這一趟,北伐便無從談起
  set: { 渡瀘之念: "無奈" }
??

:: if 渡瀘之念 == "仁政"
你親自為孟獲鬆綁,以禮相待。
諸葛亮(心聲): 「先帝在世時常說『勿以惡小而為之,勿以善小而不為』。我若連這個都做不到,何以為國?」
:: elif 渡瀘之念 == "攻心"
你不解釋,只是放了他。你知道,他若是真的心服,自己會明白;若是不服,做幾次也是無用。
諸葛亮(心聲): 「攻城為下,攻心為上。」
:: else
你走過孟獲的營地,看見南方部族裡的孩子,望著遠方走來的隊伍。
諸葛亮(心聲): 「我若有別的路可走,何至於此?」
:: endif
七擒七縱之後,孟獲終於跪伏於地——「公,天威也!南人不復反矣!」
南方,定了。
@wait 1500
你回到成都時,已是兩鬢染霜。
這一仗你贏了。但贏的代價,你一個人收著。
諸葛亮(心聲): 「該準備的,都準備好了。剩下的,就是那件我拖了太久、卻終究躲不掉的事。」
北伐。
@set 南方已定 = true
