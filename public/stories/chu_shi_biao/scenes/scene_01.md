你叫諸葛亮,字孔明。隱居在南陽隆中,以耕讀為生。
這是漢室將傾的年代。你從小就跟著叔父一路南下,離開故鄉徐州,落腳在荊州。
諸葛亮(心聲): 「那條路上見過的事,我不想再見第二次。」
你不太願意回頭想那段年少的日子。你只記得,那以後你變得比同齡人安靜。
@wait 800
這些年,你在草廬裡耕田、讀書,看著荊州一年一年變化。劉表年老,州中暗潮洶湧,荊州遲早要落到別人手裡。
你並非沒有想過出仕,只是——
諸葛亮(心聲): 「亂世裡的人物太多,真的能讓天下好一點的,卻一個也沒看到。」
所以你一直在等。等一個你願意把命壓上去的人。
你的朋友徐庶、崔州平、石廣元,一個一個都出仕了。你還在這裡,鋤頭一鋤一鋤地落在泥土裡。
@wait 1000
直到那一年冬天——
@show 劉備 center normal
有人冒著風雪敲開了你的籬笆門。他自稱劉備,是漢室宗親,如今寄居在新野。
這已經是他第三次來了。前兩次,你都託辭不在家。
劉備: 「漢室傾頹,奸臣竊命。備不度德量力,欲信大義於天下。先生大才,肯不肯出山相助?」
你看著他。他沒有地盤,沒有兵馬,連立足之地都要寄人籬下。
他要的,是一個幾乎不可能的夢。
而他,卻肯為了這個夢,向一個布衣三次屈尊。
諸葛亮(心聲): 「我等的,是不是這個人?」

:: if 出山之心 == "知遇"
你心裡某個地方被觸動了。這世間肯為一個布衣三次屈尊的人,不多。
諸葛亮: 「將軍不嫌亮淺陋,亮願效犬馬之勞。」
:: elif 出山之心 == "天下"
你想起年少時跟著叔父走過的那條路。
諸葛亮(心聲): 「若這個人真能成事,也許就能讓那種日子,別再發生。」
諸葛亮: 「亮願出山。願與將軍,共扶這將傾的天下。」
:: else
諸葛亮(心聲): 「成算渺茫。可是若連試都不敢試,我躲在這座草廬裡,又算什麼?」
諸葛亮: 「將軍既不相棄,亮,願意一試。」
:: endif
你為劉備分析天下三分之勢,定下了日後的方略——這便是後人所稱的「隆中對」。
那一年,你二十七歲。
