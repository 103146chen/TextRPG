旁白: 南方平定後,你在成都休養了一年多。修水利、勸農桑、操練軍馬、儲備糧草。你把每一件事,都當成自己最後一次能做的事去做。
諸葛亮(心聲): 「我這身子,不知道還能撐多久。」
旁白: 這些年連年奔波,你的身體越來越覺得沉。但你沒讓任何人知道。
@wait 800
旁白: 建興五年春,你站在抉擇的關口: 要不要上表北伐?
@show 譙周 center normal
旁白: 一位老臣站了出來,神色憂慮。譙周是益州的學者,先帝在時就很器重他。
譙周: 「丞相,如今天下三分,我益州本就是最弱的一方。連年用兵,民力已乏。何不休養生息,徐圖將來?」
旁白: 你沒有立刻回答。譙周說的,沒有錯。
旁白: 你比誰都清楚蜀漢的家底: 益州人口不過百萬,曹魏卻有近五百萬。論國力,你不到對方的五分之一。這一仗,勝算渺茫。
@wait 1000
旁白: 可你心裡,也有另一個聲音。
旁白: 這個抉擇,沒有人能替你做。是搏一個渺茫的機會,還是守住眼前這點安穩?

?? choice

  set: { 北伐之由: "報恩" }

  set: { 北伐之由: "理念" }
- text: 北伐——「我何嘗不知渺茫。但我這代人不去做,後人連試的機會都沒有。」
  set: { 北伐之由: "悲觀" }
- text: 不北伐——譙周說得對。守住蜀漢,休養生息,徐圖將來
  set: { 北伐之由: "偏安" }
  goto: scene_e_pianan

:: if 北伐之由 == "報恩"
諸葛亮: 「先帝三顧臣於草廬之中,臨崩寄臣以大事。此恩此義,亮唯有以死相報。」
諸葛亮(心聲): 「只要我還有一口氣,就不能讓先帝的託付落空。」
:: elif 北伐之由 == "理念"
諸葛亮: 「以攻為守,以動制靜。蜀漢若安於一隅,曹魏整頓內政,十年後便來吞我。如今我去,還能爭一爭;十年後再去,便晚了。」
:: else
諸葛亮(心聲): 「我這代人不去,後人連『可以試一試』這幾個字都沒有了。」
諸葛亮: 「諸位放心。成敗利鈍,非亮所能逆睹。但只要還在一日,亮便盡一日之力。」
:: endif
旁白: 議論漸漸平息。沒有人能再勸住你。
@wait 1000
旁白: 你回到府中,坐在燈下。
旁白: 明日就要上表了。出征之前,你還有最後一件事要做——你要親手寫一封表,寫給後主,也寫給自己。
諸葛亮(心聲): 「有些話,現在不說,怕是沒有機會了。」
旁白: 你磨墨,鋪紙,提起筆。
