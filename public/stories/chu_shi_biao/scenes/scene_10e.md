旁白: 大軍向北。「興復漢室,還於舊都。」這八個字,你寫在表上,也記在心裡。
旁白: 可你越往北走,越覺得這八個字沉重。曹魏太強,蜀漢太弱,而時間,又站在對方那一邊。

:: if 北伐之由 == "悲觀"
諸葛亮(心聲): 「我早知道難。只是沒想到,會這麼難。」
:: else
諸葛亮(心聲): 「再近一點……離舊都,再近一點就好。」
:: endif
@wait 1500
旁白: 建興十二年,秋。五丈原。
旁白: 你病倒在軍中。最後的時候,你掙扎著望向北方——那裡是中原,是長安,是你一生想還而未還的舊都。
諸葛亮(心聲): 「還差一點……就差那麼一點……」

:: if 出山之心 == "天下"
諸葛亮(心聲): 「漢室……對不起。」
:: endif
@wait 2000
旁白: 你終究沒能踏進舊都的城門。那八個字,成了你一生最大的遺憾。
@wait 2500
