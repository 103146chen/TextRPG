你出山才一年多,曹操便揮軍南下,號稱八十萬。
劉表病死,劉琮舉荊州歸降。劉備從新野一路南撤,十幾萬百姓跟著他走。
你看著那條南撤的隊伍,心裡又浮起年少時的記憶。
諸葛亮(心聲): 「同樣的事情,還在發生。」
@wait 1000
你建議劉備聯合東吳,共抗曹操。劉備派你親自過江,去說服孫權。
你抵達柴桑時,東吳的大臣們已經吵成一片——主張歸順的人比主張迎戰的還多。
@show 孫權 center normal
孫權還很年輕。他坐在堂上,神情難辨。曹操大軍壓境,東吳真要戰,確實是以小博大。
你必須說服他。可怎麼說,他才會真的下決心?

?? choice
- text: 用激將法——以「將軍若不能戰,何不束手?」逼他表態
  set: { 說吳之術: "激將" }
- text: 仔細為他剖析利害——曹軍遠來疲憊、不習水戰、北人不適南方氣候
  set: { 說吳之術: "利害" }
- text: 訴諸大義——曹操挾天子以令諸侯,將軍若降,後世如何看您?
  set: { 說吳之術: "大義" }
??

:: if 說吳之術 == "激將"
諸葛亮: 「將軍若度東吳之力能與曹操抗衡,則早早與之絕;若自度不能,何不解兵束手?」
孫權變了臉色。他離席而起,袖子一拂。但你看得出來,他不是真的要走——他被你激住了。
半晌,他坐回去。
孫權: 「先生此言……非戲我也?」
:: elif 說吳之術 == "利害"
你不疾不徐,一條一條為他分析: 曹軍遠來疲憊;北方士卒不習水戰;荊州新附,人心未服;隆冬時節,糧草補給不易,軍中已有病情傳開。
你說的每一條,都不是激情,而是事實。
孫權聽到最後,長吐了一口氣。
孫權: 「先生之言,如撥雲見日。」
:: else
你並不急著談兵勢。你先問孫權: 當年令尊起兵討董,所為何事?令兄平定江東,又所為何事?
你說: 曹操名為漢相,實為漢賊,若將軍此時束手,後世史書要如何寫您?
孫權沉默了很久。他低下頭,又抬起頭。
孫權: 「先生之言,擊中我心。」
:: endif
@hide 孫權 fade=400
不久,孫權拔出佩刀,砍下案角——「諸將吏有再言迎曹者,與此案同!」
@show 周瑜 center normal
周瑜被任命為都督,率三萬水軍與你會合。
周瑜年紀比你大幾歲,目光銳利,卻不傲慢。他看著你,微微頷首。
周瑜: 「孔明,接下來,就是我們的事了。」
@hide 周瑜 fade=600
@wait 1000
那一年冬天,赤壁。
東風吹起的時候,你站在江邊。江上的火光遠遠映過來,曹操的大軍,潰散了。
諸葛亮(心聲): 「這一仗贏了。可是這天下,離安穩,還很遠。」
@set 赤壁已勝 = true
