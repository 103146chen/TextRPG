旁白: 大軍向北而去。
旁白: 此後的歲月,你數度北伐。你事必躬親,從清晨到深夜,連最瑣碎的軍務都不肯假手他人。
諸葛亮(心聲): 「我知道我的時間不多了。能多做一點,是一點。」

:: if 北伐之由 == "報恩"
旁白: 支撐你的,始終是先帝那三顧的恩、白帝託孤的義。
:: elif 北伐之由 == "理念"
旁白: 支撐你的,是「以攻為守」的那個信念,從未動搖。
:: else
旁白: 你早知勝算渺茫。可正因為知道,你才更不肯停下——多撐一日,蜀漢便多一日。
:: endif
@wait 1500
旁白: 建興十二年,秋。五丈原。
旁白: 你病倒在軍中。秋風吹過渭水邊的營帳。你知道,這一次,是真的走到頭了。

:: if 出山之心 == "知遇"
諸葛亮(心聲): 「先帝啊……當年草廬之中,您三顧的情,亮,總算沒有辜負。」
:: elif 出山之心 == "明知不可為"
諸葛亮(心聲): 「我早知道看不到那一天。可若重來一次,我還是會走出那座草廬。」
:: else
諸葛亮(心聲): 「漢室……終究還是沒能興復。可這條路,總算有人走過了。」
:: endif
@wait 2000
旁白: 你用一生,履行了那句「鞠躬盡瘁,死而後已」。
諸葛亮(心聲): 「我這一生,問心無愧。」
@wait 2500
@ending id="ending_鞠躬盡瘁" title="鞠躬盡瘁" desc="你明知此生看不到中原,仍走完了北伐的路。五丈原的秋風裡,你履行了對先帝的全部承諾——鞠躬盡瘁,死而後已。漢室終究未興,但你問心無愧。"
