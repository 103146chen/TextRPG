大軍向北。此後你一次又一次出師,為了你心中的那個信念,幾乎傾盡了蜀中的人力與物力。
糧不夠,你便屯田;路難行,你便造木牛流馬。只要還有一分可能,你就不肯停。

:: if 北伐之由 == "理念"
諸葛亮(心聲): 「若連我都退了,這天下,還有誰記得『漢』這個字?」
:: else
諸葛亮(心聲): 「停不下來了。走到這一步,已經沒有回頭的路。」
:: endif

有人敬你忠貞不二,也有人嘆息:連年用兵,最辛苦的,終究是益州的百姓。
@wait 1500
建興十二年,秋。五丈原。
你終於還是病倒了。直到最後,你心裡記掛的,依舊是北方那片從未踏入的中原。
諸葛亮(心聲): 「再給我一點時間……只要再一點……」
@wait 2000
你至死方休。這份執著,是偉大,還是負擔?這個問題,你留給了後人。
@wait 2500
