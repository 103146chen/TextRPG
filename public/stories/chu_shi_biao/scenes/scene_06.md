治蜀的這些年,過得並不輕鬆。
你親自批每一件公文,從清晨到深夜。修法度、平賦稅、安百姓——這個國,是你一個字一個字撐起來的。
可後主始終讓你放不下心。你勸過、諫過、立過規矩,他答應得很好,過些日子又回到老樣子。
@wait 800
這一夜,你又批公文到很晚。燈花爆了一下,你忽然覺得很累——不是身體的累,是更深的那種。
諸葛亮(心聲): 「先帝,您把這個國交給我,可您也看見了,陛下他……」
就在這時,先帝臨終的那句話,又回到了你耳邊。
諸葛亮(心聲): 「若嗣子可輔,輔之;如其不才……君可自取。」
你放下筆。這句話,你已經很多年沒有讓自己想起了。
今夜它回來了——帶著這些年所有的疲憊,一起壓上來。
@wait 1000
這間屋子裡,只有你和那盞燈。沒有人會知道你今夜想了什麼。
你問自己: 這副擔子,你還要扛多久?還扛得動嗎?

:: if 臣節 == "純臣"
諸葛亮(心聲): 「不必想了。這條心,從草廬那天起,就沒有變過。陛下能不能成器,是一回事;我盡不盡臣節,是另一回事。」
:: elif 臣節 == "認命"
諸葛亮(心聲): 「我只能做我能做的。輔到不能輔為止。剩下的,不是我管得了的。」
:: else
諸葛亮(心聲): 「……我竟也會有那樣的念頭。」
你被自己嚇了一跳。那念頭只閃了一瞬,你便把它按回了最深的地方,再用一生的忠誠把它封死。
諸葛亮(心聲): 「正因為動過這個念頭,我才更要走得乾乾淨淨,讓任何人都挑不出半點私心。」
:: endif
你重新提起筆,把那疊公文批完。
窗外更鼓敲過。你知道,只要你還坐在這盞燈下,這個國就還撐得住。
諸葛亮(心聲): 「再撐一撐吧。總還有些事,只有我能做。」
