先帝崩後,後主劉禪即位,改元建興。蜀漢的擔子,全壓在你一個人肩上。
@show 劉禪 center normal
後主即位時十七歲,性子寬和,卻也耳根子軟,容易親近身邊那些會說話的人。
你看著他在朝堂上的樣子——先帝的兒子,卻沒有先帝的眉宇。先帝會在最該堅持的時候堅持,後主卻常常在最不該讓步的時候讓步。
諸葛亮(心聲): 「陛下年紀還輕。長大了,自然會懂的。」
你願意這樣相信。
@wait 800
@show 黃皓 right normal
但問題很快就來了。朝中有個近臣,整日陪後主玩樂,說的話總順著後主的心意。漸漸地,後主什麼都聽他的。
你想起先帝臨終的囑咐——「待之如子」。
可你也想起前漢、後漢這幾百年的興衰。讀過《史記》《漢書》的人都明白: 前朝的覆轍,就擺在眼前。
諸葛亮(心聲): 「親賢臣,遠小人,此先漢所以興隆也;親小人,遠賢臣,此後漢所以傾頹也。」
這個道理,你比誰都清楚。
你必須做點什麼。

@hide 黃皓 fade=400

:: if 治國之道 == "直諫"
你跪奏於前,把話說得分明。
諸葛亮: 「陛下,親賢遠佞,方是社稷之福。此人不可再近。」
後主低下頭,唯唯諾諾地應了。
諸葛亮(心聲): 「他答應了。可他是真聽進去了,還是只是怕我?」
你心裡並沒有真正放下。
:: elif 治國之道 == "制度"
你沒有急著扳倒誰。你訂下規矩——宮中、府中,俱為一體;賞罰褒貶,不應因人而異。
諸葛亮(心聲): 「人會走,會變。唯有法度立住了,才能不靠一個人撐著。」
這幾年,你親自批每一件公文,從清晨到深夜,連最瑣碎的案件都要過目。
有人勸你別把自己累壞了,你只是笑笑——你知道,你立的這套東西,還太年輕,離不開你。
:: else
你按住了想說的話。朝局未穩,貿然動手,只怕牽一髮而動全身。
諸葛亮(心聲): 「再等等。有些事,急不得。」
你把這份憂慮,悄悄記在了心底。
你開始更頻繁地進宮陪後主——他願意聽你的時候,你就多說幾句;不願意聽的時候,你就改天再說。
:: endif
@hide 劉禪 fade=600
@wait 1000
你比任何人都明白: 你不可能永遠待在後主身邊。有一天你會離開——去北方,或者,去更遠的地方。
到那時,這個朝廷,撐得住嗎?
這個問題,你不敢深想。但你也知道,你必須開始為那一天做準備。
