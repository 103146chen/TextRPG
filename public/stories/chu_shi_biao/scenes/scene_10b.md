大軍向北。可你心裡清楚,這條路上,真正與你同行的人,太少了。
朝中有人勸你休兵,有人不解你為何屢屢出師。後主雖未阻攔,卻也從未真正明白你為什麼非走不可。

:: if 治國之道 == "隱忍"
你想起當年朝堂上那些你按下沒說的話。原來有些憂慮,注定只能一個人扛。
:: elif 治國之道 == "直諫"
你直言進諫過,可話說得再重,聽的人若不懂,也只是徒然。
:: else
你立下的法度還在運轉,可法度約束得了行為,約束不了人心的疏遠。
:: endif

諸葛亮(心聲): 「沒有人懂,也好。只要這件事是對的,懂不懂,又有什麼關係。」
@wait 1500
建興十二年,秋。五丈原。
你病倒在軍中。身邊沒有先帝,沒有知己,只有一盞將盡的燈,和一卷還沒寫完的兵書。

:: if 託孤之諾 == "泣"
諸葛亮(心聲): 「先帝,當年白帝城,臣連一句完整的話都說不出。如今……臣也快要來見您了。」
:: else
諸葛亮(心聲): 「這條路,我一個人走完了。剩下的,就交給後來的人吧。」
:: endif

@wait 2000
世人記得你的功業,卻很少有人,真正走進過你的孤獨。
@wait 2500
@ending id="ending_孤臣" title="孤臣" desc="滿朝無人真正懂你為何非北伐不可。你獨自扛起興復漢室的重擔,在無人理解中走到了五丈原。你是忠臣,也是一個徹底孤獨的人。"
