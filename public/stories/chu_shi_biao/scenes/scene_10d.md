大軍向北。你把該做的,都做了。
表上得明明白白,賢才薦得清清楚楚,朝中的法度也都安排妥當。

:: if 治國之道 == "制度"
你立的那套法度,還在運轉。即使你不在,它也能撐住一陣子。
:: else
你能交代的都交代了。能不能傳下去,你已經不去想了。
:: endif

諸葛亮(心聲): 「謀事在人,成事在天。我已盡人事,剩下的,就交給天吧。」
@wait 1500
建興十二年,秋。五丈原。
你病倒在軍中。可這一回,你心裡竟是難得的平靜。

:: if 出山之心 == "知遇"
諸葛亮(心聲): 「先帝,您的知遇,亮報了。可以歇一歇了。」
:: else
諸葛亮(心聲): 「該交代的都交代了。可以歇一歇了。」
:: endif

@wait 2000
你閉上眼睛,像是放下了背了一生的擔子。
@wait 2500
