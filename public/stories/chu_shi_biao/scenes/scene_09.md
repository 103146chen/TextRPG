夜深了。燈下,只有你一個人。
明天大軍就要開拔。出征之前,你想對後主說的話,太多太多。
諸葛亮(心聲): 「我這一去,不知何時能回。有些話,現在不說,怕是沒有機會了。」
你深吸一口氣,把筆尖,放上紙面。
@wait 1000
諸葛亮(獨白): 「臣亮言:先帝創業未半,而中道崩殂。今天下三分,益州疲弊,此誠危急存亡之秋也。」

:: if 託孤之諾 == "死而後已"
諸葛亮(心聲): (白帝那一夜,我說了『繼之以死』。那句話,我不能不算數。)
:: elif 託孤之諾 == "泣"
諸葛亮(心聲): (那一夜我說不出話。先帝按了按我的頭。他懂的——這份懂,比任何承諾都重。)
:: else
諸葛亮(心聲): (白帝城那一夜……不管當時答了什麼,如今這擔子,終究是我的。)
:: endif
@wait 800
諸葛亮(獨白): 「然侍衛之臣,不懈於內;忠志之士,忘身於外者,蓋追先帝之殊遇,欲報之於陛下也。誠宜開張聖聽,以光先帝遺德,恢弘志士之氣;不宜妄自菲薄,引喻失義,以塞忠諫之路也。」
諸葛亮(心聲): (陛下,您年紀還輕。願意聽,願意問,就還有路。)
@wait 800
諸葛亮(獨白): 「宮中府中,俱為一體;陟罰臧否,不宜異同。若有作姦犯科,及為忠善者,宜付有司,論其刑賞,以昭陛下平明之理;不宜偏私,使內外異法也。」

:: if 治國之道 == "制度"
諸葛亮(心聲): (這幾年我立的法度,寫進這幾句裡了。我若不在了,法度還能撐一陣子。)
:: elif 治國之道 == "直諫"
諸葛亮(心聲): (我直諫過陛下。我希望這幾句寫下來,他能再記久一點。)
:: else
諸葛亮(心聲): (我一直隱忍。但這份隱忍,不能成為陛下偏私的藉口。)
:: endif
@wait 800
諸葛亮(獨白): 「侍中、侍郎郭攸之、費禕、董允等,此皆良實,志慮忠純,是以先帝簡拔以遺陛下。愚以為宮中之事,事無大小,悉以咨之,然後施行,必能裨補闕漏,有所廣益。」
諸葛亮(獨白): 「將軍向寵,性行淑均,曉暢軍事,試用於昔日,先帝稱之曰能,是以眾議舉寵為督。愚以為營中之事,悉以咨之,必能使行陣和睦,優劣得所。」
諸葛亮(心聲): (這些人,是我留給陛下的。他們在,蜀漢的根就還在。)
@wait 800
諸葛亮(獨白): 「親賢臣,遠小人,此先漢所以興隆也;親小人,遠賢臣,此後漢所以傾頹也。先帝在時,每與臣論此事,未嘗不歎息痛恨於桓、靈也!侍中、尚書、長史、參軍,此悉貞良死節之臣,願陛下親之、信之,則漢室之隆,可計日而待也。」
諸葛亮(心聲): (那個整日陪在陛下身邊的人……陛下,您記得我說過的話嗎?)
@wait 1200
諸葛亮(獨白): 「臣本布衣,躬耕於南陽,苟全性命於亂世,不求聞達於諸侯。先帝不以臣卑鄙,猥自枉屈,三顧臣於草廬之中,諮臣以當世之事,由是感激,遂許先帝以驅馳。」

:: if 出山之心 == "知遇"
諸葛亮(心聲): (草廬那個風雪的午後……我這一生,從那一刻就決定了。)
:: elif 出山之心 == "天下"
諸葛亮(心聲): (我那時想的是天下。如今想想,先帝給我的,遠不只是一個天下的機會。)
:: else
諸葛亮(心聲): (我那時想的是『試一試』。沒想到這一試,試了一輩子。)
:: endif
@wait 800
諸葛亮(獨白): 「後值傾覆,受任於敗軍之際,奉命於危難之間,爾來二十有一年矣。」

:: if 勸阻東征 == "暗備"
諸葛亮(心聲): (荊州失了的那一年,我擋不住先帝。最後我能做的,只是把退路備好。)
:: elif 勸阻東征 == "直諫"
諸葛亮(心聲): (我那時直諫了。可有些話,先帝聽見了,卻聽不進去。)
:: else
諸葛亮(心聲): (我那時哭過。可眼淚也擋不住該來的事。)
:: endif
@wait 1000
諸葛亮(獨白): 「先帝知臣謹慎,故臨崩寄臣以大事也。受命以來,夙夜憂歎,恐託付不效,以傷先帝之明。故五月渡瀘,深入不毛。」

:: if 渡瀘之念 == "仁政"
諸葛亮(心聲): (瀘水那一段,我一直記得。我盡量讓那條路上,少幾分傷。)
:: elif 渡瀘之念 == "攻心"
諸葛亮(心聲): (七擒七縱。我要的不是一仗的勝負,是十年的安穩。)
:: else
諸葛亮(心聲): (瀘水那一段……不該想太多。想多了,就走不下去了。)
:: endif
@wait 800
諸葛亮(獨白): 「今南方已定,兵甲已足,當獎率三軍,北定中原,庶竭駑鈍,攘除姦凶,興復漢室,還於舊都。此臣所以報先帝而忠陛下之職分也。」

:: if 北伐之由 == "報恩"
諸葛亮(心聲): (報先帝,忠陛下。這六個字,把我的一生交代了。)
:: elif 北伐之由 == "理念"
諸葛亮(心聲): (以攻為守,以動制靜。這條路,我選了,就要走到底。)
:: else
諸葛亮(心聲): (我這代人不去,後人連試的機會都沒有。)
:: endif
@wait 800
諸葛亮(獨白): 「至於斟酌損益,進盡忠言,則攸之、禕、允之任也。願陛下託臣以討賊興復之效;不效,則治臣之罪,以告先帝之靈。若無興德之言,則責攸之、禕、允等之慢,以彰其咎。」
諸葛亮(獨白): 「陛下亦宜自課,以諮諏善道,察納雅言,深追先帝遺詔。臣不勝受恩感激。」
@wait 1000

:: if 臣節 == "曾動搖"
諸葛亮(心聲): (那一夜我也動過一個念頭。可正因為動過,我這封表,才要寫得比誰都乾淨。)
:: elif 臣節 == "認命"
諸葛亮(心聲): (我扛到了今天。剩下的路,我也會扛下去——扛到扛不動為止。)
:: else
諸葛亮(心聲): (從草廬到今夜,我這條臣節,沒有變過。)
:: endif
@wait 800
諸葛亮(心聲): (該說的,都說了。)
諸葛亮(獨白): 「今當遠離,臨表涕零,不知所言。」
@wait 2000
你停下筆。眼淚不知何時落在了紙上,把最後幾個字洇開了一點。
你沒有去擦。
@wait 1500
天,快亮了。
