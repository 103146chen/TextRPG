旁白: 赤壁之後的這些年,你輔佐劉備取荊州、入益州、奪漢中,終於有了三分天下的根基。建安二十六年,劉備在成都即位,國號漢,改元章武。
旁白: 你成了丞相。這條路,從草廬走到成都,走了整整十四年。
諸葛亮(心聲): 「總算……走到這一步了。」
@wait 800
旁白: 然而你心裡始終放不下一件事——關羽鎮守的荊州。
旁白: 荊州是隆中對裡天下三分的關鍵。失了荊州,你定下的那條「兩路出師、北定中原」的策略,就斷了一條手臂。
旁白: 而那一年的消息,終於還是傳來了。
@show 信使 center normal
旁白: 信使一進來就跪下。
信使: 「丞相……荊州……失了。關將軍……也沒能回來。」
@wait 1200
旁白: 你呆站了很久。
諸葛亮(心聲): 「敗了……我擔心的事,終究還是發生了。」
@hide 信使 fade=400
@wait 1000
旁白: 更壞的消息接連而來。先帝聞訊,當著群臣的面立誓要起傾國之兵,東征孫權。
旁白: 這時候,你必須站出來說話了。
旁白: 你比誰都清楚——若此時東征,蜀漢必受重創。曹魏正等著看戲;東吳兵精糧足,且占有地利;最關鍵的是,先帝此刻情緒激動,不能客觀作戰。
旁白: 你必須勸阻。可是,要怎麼勸?

?? choice
- text: 以天下大局直諫——曹魏才是國賊,不該為私怨損國本
  set: { 勸阻東征: "直諫" }
- text: 哭諫——跪伏於地,以「臣不忍見蜀漢自損」相求
  set: { 勸阻東征: "哭諫" }
- text: 知道先帝必不聽勸——表面不阻,暗中為他準備退路與後援
  set: { 勸阻東征: "暗備" }
??

@show 劉備 center angry

:: if 勸阻東征 == "直諫"
旁白: 你跪下,把話說得分明: 漢賊不在江東,在中原。今因兄弟之情,而棄天下之義,曹魏必喜,而百姓必苦。
旁白: 劉備聽完,沉默了很久。然後,他緩緩抬頭。
劉備: 「丞相之言,朕都明白。可是雲長與朕,情同骨肉。此情若不還,朕——朕無顏再坐這個位子。」
旁白: 你看著他通紅的眼睛,知道再說也是無用。
:: elif 勸阻東征 == "哭諫"
旁白: 你跪伏在地,把額頭貼在冰涼的青磚上。
諸葛亮: 「陛下,臣求陛下三思。蜀漢初立,根基未穩。此戰若有失,二十年的心血,將毀於一旦。臣……不忍見此。」
旁白: 劉備上前,扶起了你。他的手在顫。
劉備: 「丞相起來。朕……朕知道丞相的心。可是雲長之事,朕咽不下這口氣。」
:: else
旁白: 你沒有直言反對。先帝此刻聽不進任何反對的話——多年的兄弟情,你比誰都清楚。
旁白: 你退下後,連夜安排: 漢中的防務、糧草、後備的兵力、撤退路線——你把每一步,都默默準備好了。
諸葛亮(心聲): 「我擋不住他。但我至少要讓他,有路可退。」
:: endif
@hide 劉備 fade=600
@wait 1000
旁白: 那一年夏天,先帝親率大軍,東征孫權。
旁白: 你站在城頭,送行的隊伍綿延數里。你看著那面「漢」字大旗遠去,心裡明白——
諸葛亮(心聲): 「這一去,難料。」
@set 東征已起 = true
