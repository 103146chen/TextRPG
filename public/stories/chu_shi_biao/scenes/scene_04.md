夷陵的消息傳回成都時,你正在處理朝中政務。
信使一進來,只說了幾個字,就再也說不下去。
你閉上眼睛,深吸了一口氣。
諸葛亮(心聲): 「該來的,還是來了。」
@wait 1000
先帝退守白帝城,連夜不能合眼,病倒了。御醫送來的奏報越來越壞,你連夜起身,趕往白帝。
@show 劉備 center sick
病榻上的先帝,氣息微弱。看見你的那一瞬,眼睛裡才有了些光。
劉備: 「丞相……你來了。」
你跪在床邊,握著他的手。那隻手,曾經在草廬裡握過你的手,在赤壁江邊拍過你的肩,在成都即位時舉過杯。
如今這隻手,瘦得幾乎沒有重量。
劉備: 「朕……不行了。」
他停了很久,才把下一句話說出來。
劉備: 「丞相之才,十倍於曹丕,必能安國,終定大事。若嗣子可輔,輔之;如其不才……」
@wait 1500
劉備: 「君可自取。」
你渾身一震。
諸葛亮(心聲): 「君可自取」——他竟把這樣的話,說給一個臣子聽。
這句話太重了。你從沒想過,有一天會聽到這樣的話。
先帝的目光仍停在你臉上,等著你的回答。

  set: { 託孤之諾: "死而後已" }

- text: 惶恐伏地:「陛下何出此言!臣安敢有異心!」

:: if 託孤之諾 == "死而後已"
諸葛亮: 「臣必竭股肱之力,效忠貞之節,繼之以死!」
先帝聽了,神情似乎安定了些。他點了點頭,沒有再說話。
:: elif 託孤之諾 == "泣"
你說不出一句完整的話。千言萬語,最後都化成了無聲的叩首。
先帝伸出手,輕輕按了按你的頭。他懂的。
:: else
諸葛亮: 「陛下何出此言!臣安敢有異心!臣事陛下,自當鞠躬盡瘁,至死方休!」
先帝看著你,眼裡有一絲說不清的東西,像是安慰,又像是歉疚。
:: endif
先帝喘了幾口氣,又輕聲囑咐了你幾件事——劉禪年幼,要你像對待自己的孩子那樣待他;東吳之事,可以結好,不必再戰;漢中與南中的防務,要你親自上心。
你一一應下。每一個字,你都記在了心裡。
@wait 1500
不久,先帝在白帝城走了。
@hide 劉備 fade=1500
@wait 1500
你扶柩回成都。一路上,你沒有掉一滴眼淚——因為你知道,從今往後,你是整個蜀漢唯一還能哭的人,但你不能哭。
那句「君可自取」,從此像一根細刺,留在你心裡。
你不知道,它將在很多很多年後的某個夜晚,重新回到你面前。
@set 先帝已崩 = true
